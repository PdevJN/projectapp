# projectapp

プロジェクトのタスクを**ガントチャート**で管理するデスクトップアプリです。

メンバーの「作業の速さ(相対比率)」と「その仕事にかける時間の割合(割り当て率)」から、**完了予定を自動で計算**します。人が足りているか、遅れていないかは、ダッシュボードで確かめられます。

- 細かい仕様は [CLAUDE.md](./CLAUDE.md)(入口)と [.claude/spec/](./.claude/spec/)
- 開発者向けの情報(構成・テスト)は [docs/development.md](./docs/development.md)

## 使いはじめる

Python 3.13 以上と [uv](https://docs.astral.sh/uv/) が必要です。

```bash
uv sync                                 # 初回だけ
uv run projectapp                       # 起動(ネイティブウィンドウ)
```

ブラウザで使うこともできます。

```bash
uv run projectapp --mode web            # ブラウザで開く
uv run projectapp --mode web --port 9000
```

> **Web モードの注意**: このマシンの `127.0.0.1` だけで待ち受けます(認証はないので、LAN には出しません)。ファイルやフォルダを選ぶ機能(画像・PlantUML の保存、各種の取り込み・書き出し、格納先の変更)は、ネイティブウィンドウでだけ使えます。

## できること

### 計画を立てる(ガントチャート)

- 日次・週次・月次に切り替えて表示し、タスクはセクション(3 階層まで)でまとめられます。
- 祝日・土日・イベント(キャンペーンや休業日など)を、背景の色で見分けられます。締切は ◆、今日は赤い線で示します。
- 色で状況が分かります。
  - **棒の色**: 状態(未着手・実行中・一時停止・終了)
  - **名前欄の背景**: 優先度
  - **赤い行**: 予定や締切を過ぎたタスク(遅れ)
  - **黄色い行**: このままだと完了予定に間に合いそうにないタスク(警告)
  - **縞模様**: 同じ人への割り当てが 100% を超える期間
- ドラッグで、行の並べ替えやコピー、バーの横移動(日次)ができます。Option を押して落とすとコピーです。
- 検索や担当者・チームでの絞り込み、セクションの折りたたみ、複数タスクの一括編集・一括削除ができます。

### タスクを書く

- 開始予定・完了予定・締切・工数・担当者・カテゴリ・優先度・状態・進捗度・リンクを入れられます。日付は `10/15` のような短い書き方でも入力できます。
- **完了予定は自動計算**されます(工数・稼働可能時間・祝日・担当者から)。手で決めることもできます。
- 先行タスクを矢印でつなげます。締切だけを持つ「チェックポイント」、複数のタスクをまとめる「まとめ」もあります。
- 1 つのタスクを複数に分けたり(分解)、選んだタスクを別のプロジェクトに切り出したり(子プロジェクト)できます。
- 実際に作業した日時(実績)を、1 区間または複数区間で記録できます。予定と重ねて表示します。

### 人とチームを管理する

- メンバーごとに「基本比率」を決め、プロジェクト共通の「パラメータ」(経験・難易度など)で調整します。これが完了予定の計算に使う**相対比率**になります。
- 1 つのタスクに複数の担当者を割り当てられます。週ごとに担当を変えることもできます。
- 休みの日や、土日に出勤する日を、メンバーごとに登録できます。
- メンバーをチームにまとめられます(兼務も可)。

### 状況を確かめる(ダッシュボード)

次の 4 つを、今週・今月・全期間・指定した期間で集計します(読み取り専用)。

- **進捗と遅れ**: 進捗率、状態ごとの件数、遅れているタスク
- **人ごとの負荷**: 負荷の平均と最大、100% を超えた日数
- **工数の予定と実績**
- **期限とマイルストーン**

「残りの工数と必要人数」では、期限までに終わらせるのに人が足りるかが分かります。複数のプロジェクトを重ねた負荷も見られます。条件とカードの並びは、名前をつけて保存できます。

### 保存する・共有する

- プロジェクトは **JSON ファイル 1 つ**です(既定の置き場所は `~/.projectapp/`)。保存の前に、他で書き換えられていないか確かめます。
- 置き場所が git のフォルダなら、アプリの中から状態の確認・コミット・プッシュ・プルができます。複数人が同じファイルを変えたときは、タスク単位で自動的にまとめ、同じ項目が食い違ったときだけ、どちらを採るかを画面で選びます。
- 元に戻す・やり直し(`Cmd/Ctrl+Z`)が使えます。

### 取り込む・書き出す

| 取り込み | 書き出し |
|---|---|
| PlantUML のガント | チャートプレビュー(画像として保存、PlantUML として保存) |
| CSV / TSV(Smartsheet のテンプレートの形) | TSV |
| 設定ファイル(メンバー・カテゴリなど) | 設定ファイル |
| | 担当者向けのタスク一覧(todoapp の形式) |

### 見た目

- テーマは、自動(システムに合わせる)・ライト・ダーク・カスタム(色を指定)から選べます。
- 画面全体を 70〜200% に拡大・縮小できます。名前欄の幅は、右端のドラッグで変えられます。

## データの置き場所

| ファイル | 内容 |
|---|---|
| `~/.projectapp/<プロジェクト名>.json` | プロジェクト 1 つ分(メンバー・タスク・実績・設定など) |
| `~/.projectapp/config.json` | テーマ、画面の倍率、名前欄の幅、ダッシュボードのビュー、プロジェクトの置き場所(`project_dir`)など |
| `~/.projectapp/holidays.json` | 祝日のキャッシュ(内閣府の CSV。初回に自動で取得。「ファイル」メニューの「祝日を更新」で更新) |

プロジェクトの置き場所は、「ファイル」メニューの「格納先を変更」で変えられます。`config.json` と `holidays.json` は、変えても `~/.projectapp/` に残ります。

## キーボード操作

一覧は、「ヘルプ」→「ショートカットヘルプ」(`?`)でも見られます。`Ctrl/Cmd` は macOS では Cmd です。

| キー | 機能 |
|---|---|
| `Ctrl/Cmd+S` / `Ctrl/Cmd+Shift+S` | 上書き保存 / 名前をつけて保存 |
| `Ctrl/Cmd+O` / `Ctrl/Cmd+N` | 開く / 新規プロジェクト作成 |
| `Ctrl/Cmd+,` / `Ctrl/Cmd+Shift+M` | 設定 / メンバーとパラメータ |
| `Ctrl/Cmd+P` / `Ctrl/Cmd+E` | チャートプレビュー / 担当者へ書き出し |
| `Ctrl/Cmd+K` / `Ctrl/Cmd+Shift+K` / `Ctrl/Cmd+Shift+L` | git のコミット / プッシュ / プル |
| `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | 元に戻す / やり直す |
| `Ctrl/Cmd++` / `Ctrl/Cmd+-` / `Ctrl/Cmd+0` | 拡大 / 縮小 / 100% に戻す |
| `d` / `/` / `?` | ダッシュボード / 検索欄へ移る / ショートカットヘルプ |
| `t` / `b` / `f` / `g` | ガントチャートを 当日 / 基準日 / 最初のタスク / 指定した日付 へ移す |
| `[` / `]` | ガントチャートを 前の週 / 次の週 へ移す |
| `ESC` | ダイアログを閉じる(プレビュー・ダッシュボードから戻る) |

文字キー(`d`・`/`・`?`・`t`・`b`・`f`・`g`・`[`・`]`)と、元に戻す・やり直しは、入力欄にフォーカスがあるときは効きません(入力欄では文字の取り消しになります)。
