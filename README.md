# projectapp

プロジェクトのタスクをガントチャートで管理し、メンバーのリソース(相対比率・割り当て率)から完了予定を算出するネイティブアプリ。機能の詳しい仕様は [CLAUDE.md](./CLAUDE.md)、開発者向けの情報は [docs/development.md](./docs/development.md) を参照。

## セットアップ

Python 3.13 以上と [uv](https://docs.astral.sh/uv/) が必要。

```bash
uv sync
```

## 起動

```bash
uv run projectapp                       # ネイティブウィンドウのみ(既定)
uv run projectapp --mode web            # Web のみ(ブラウザを開く)
uv run projectapp --mode web --port 9000
```

既定は、pywebview によるネイティブウィンドウだけで起動する(ポートはランダム)。`web` は、既定のブラウザで開く。Web は、このマシンの `127.0.0.1` だけで待ち受け、LAN には出ない(認証はない)。ファイル保存・フォルダ選択のダイアログを使う機能(画像・PlantUML の保存、担当者向けファイルの書き出し、PlantUML の取り込み、格納先の変更)は、ネイティブウィンドウでだけ使える(Web では通知で断る)。

## 主な機能

**ガントチャート**
- 日次・週次・月次の切り替え、セクション(3 階層まで)、土日祝の背景色、イベント(期間の帯と色)、締切の ◆
- 検索・担当者での絞り込み、セクションの折りたたみ、行のドラッグ移動(Option を押して落とすとコピー)、日次でバーを横にドラッグして開始予定をずらす
- 棒の色は状態(未着手・実行中・一時停止・終了)、名前欄の背景は優先度。予定超過は赤み、割り当て超過は縞で示す
- 名前の欄の幅は、右端のドラッグで変えられる

**タスク**
- 開始予定・完了予定・締切・工数(時間・日・週・月)・担当者・割り当て率・カテゴリ・色・優先度・状態・進捗度・リンク(URL)を編集。日付・時刻は省略形でも入力できる
- 完了予定は、工数・稼働可能時間・祝日・担当者の換算率から自動算出する(手で指定も可。手で指定のときも算出値を参考に出す)
- 先行タスクで連結(矢印)。チェックポイント(締切だけを持つ節目)
- 実績は、簡易(1 区間)か区間(複数)で記録し、予定と重ねて表示。進捗度は 1 つの欄で入れ、遅れ・前倒しを表示する

**メンバーとリソース**
- メンバーごとの基本比率と、プロジェクト共通のパラメータ(段階の判定値)から、相対比率(10〜300%)を決める
- 同じ担当者の割り当て率が 100% を超える期間は、棒の縞と、保存時の通知で示す

**ダッシュボード**
- 進捗と遅れ、人ごとの負荷、工数の予定と実績、期限とマイルストーンを、今週・今月・全期間で集計する(読み取り専用)

**編集の支え**
- 元に戻す・やり直し(`Cmd/Ctrl+Z`・`Cmd/Ctrl+Shift+Z`。50 件)
- 画面全体の拡大・縮小(70〜200%)

**ファイルと git**
- プロジェクトは、格納先(既定は `~/.projectapp/`)の JSON 1 ファイル。コンボボックスまたは一覧から開く。保存前に外部の変更を検知する
- 格納先が git の作業ツリーなら、状態の表示、コミット、プッシュ、プル(`id` によるタスク単位の 3 者マージ)ができる

**入出力**
- チャートプレビュー(読み取り専用)から、PNG 画像・PlantUML として保存
- PlantUML のガントの取り込み(新規プロジェクトを作る)
- 担当者向けファイル(todoapp 形式の `todos.json`)の書き出し

**テーマ**
- 自動(システムに追従)・ライト・ダーク・カスタム(色を指定)

### まだないもの

- 添付ファイル(PDF・画像)
- ドラッグでの連結と、矢印のクリックでの連結の解除
- 担当者からの返送の取り込み

## データの保存先

| ファイル | 内容 |
|---|---|
| `~/.projectapp/<プロジェクト名>.json` | プロジェクト 1 つ分(メンバー・パラメータ・セクション・タスク・実績・リンク・カテゴリ・イベント・稼働設定) |
| `~/.projectapp/config.json` | テーマ、カスタムの色、名前欄の幅、画面の倍率、タスクのダイアログのレイアウト、格納先(`project_dir`) |
| `~/.projectapp/holidays.json` | 祝日データのキャッシュ(内閣府 CSV。初回のみ自動取得し、「ファイル」メニューの「祝日を更新」で更新) |

プロジェクトファイルの格納先は、「ファイル」メニューの「格納先を変更」で変えられる。`config.json` と `holidays.json` は、格納先を変えても `~/.projectapp/` に残る。

## キーボード操作

一覧は、ヘッダーの「ヘルプ」→「ショートカットヘルプ」(`?`)でも見られる。`Ctrl/Cmd` は macOS では Cmd。

| キー | 機能 |
|---|---|
| `Ctrl/Cmd+S` / `Ctrl/Cmd+Shift+S` | 上書き保存 / 名前をつけて保存 |
| `Ctrl/Cmd+O` / `Ctrl/Cmd+N` | 開く / 新規プロジェクト作成 |
| `Ctrl/Cmd+,` / `Ctrl/Cmd+Shift+M` | 設定 / メンバーとパラメータ |
| `Ctrl/Cmd+P` / `Ctrl/Cmd+E` | チャートプレビュー / 担当者へ書き出し |
| `Ctrl/Cmd+K` / `Ctrl/Cmd+Shift+K` / `Ctrl/Cmd+Shift+L` | git のコミット / プッシュ / プル |
| `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | 元に戻す / やり直す |
| `Ctrl/Cmd++` / `Ctrl/Cmd+-` / `Ctrl/Cmd+0` | 拡大 / 縮小 / 100% に戻す |
| `d` / `/` / `?` | ダッシュボード / 検索欄へ移る / ショートカットヘルプ |
| `ESC` | ダイアログを閉じる(プレビュー・ダッシュボードから戻る) |

文字キー(`d`・`/`・`?`)と元に戻す・やり直しは、入力欄にフォーカスがあるときは効かない(入力欄では文字の取り消しになる)。
