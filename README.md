# projectapp

プロジェクトのタスクをガントチャートで管理し、メンバーのリソース(相対比率・割り当て率)から完了予定を算出するネイティブアプリ。詳細な機能仕様は [CLAUDE.md](./CLAUDE.md) を参照。

## セットアップ

Python 3.13 以上と [uv](https://docs.astral.sh/uv/) が必要。

```bash
uv sync
```

## 起動

```bash
uv run projectapp
```

pywebviewによるネイティブウィンドウが起動する。

## 主な機能

- **ガントチャート**: 日次・週次・月次の切り替え、セクション、土日祝の背景色、締切の◆、タスクの状態・優先度・進捗の表示
- **タスク**: 開始予定・完了予定・締切・工数・担当者・割り当て率・ProjectCode・色・優先度・状態を編集。完了予定は工数・稼働時間・祝日から自動算出(手で指定も可)
- **実績**: 簡易(1区間)または区間(複数)で記録し、予定と重ねて表示。進捗度に応じて遅延・前倒しを表示
- **メンバー**: 名前と相対比率(10〜300%)で管理。同じ担当者の割り当て率が100%を超える期間は、棒の縞と保存時の通知で示す
- **操作**: 検索・担当者での絞り込み、セクション見出しの矢印でタスクを折りたたみ、行のドラッグ移動、Option を押して落とすとコピー、日次でバーを横にドラッグして開始予定をずらす
- **プロジェクトファイル**: `~/.projectapp/` のJSONをコンボボックスまたは一覧から開く。未保存の変更があるときは確認を表示
- **エクスポート**: 読み取り専用のプレビューで期間・スケール・表示項目を選び、PNG画像として保存(ネイティブウィンドウのみ)
- **テーマ**: 自動(システムに追従)・ライト・ダーク

まだないもの: タスク同士の連結(矢印)、添付ファイル。

## データの保存先

| ファイル | 内容 |
|---|---|
| `~/.projectapp/<プロジェクト名>.json` | プロジェクト1つ分(メンバー・セクション・タスク・実績・稼働設定) |
| `~/.projectapp/config.json` | テーマ |
| `~/.projectapp/holidays.json` | 祝日データのキャッシュ(内閣府CSV。初回のみ自動取得し、ヘッダーの「ファイル」メニューの「祝日を更新」で更新) |

## キーボード操作

| キー / 操作 | 機能 |
|---|---|
| `ESC` | エクスポートのプレビューからメイン画面へ戻る |
| `ESC` | タスク編集ダイアログを閉じる(変更があるときは確認) |
| 検索欄で `Enter` | 検索を確定(日本語入力の変換確定の `Enter` は無視) |

ヘッダー右端のテーマのメニューからテーマ(自動/ライト/ダーク)を切り替えられる。設定は`~/.projectapp/config.json`に保存され、次回起動時に復元される。ヘッダーの「ヘルプ」メニューの「ショートカットヘルプ」からキー操作の一覧を確認できる(現状、一覧は空で、上の表が実際の操作)。
