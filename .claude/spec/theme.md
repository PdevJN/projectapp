# テーマ・ヘルプ・表示設定

> `CLAUDE.md` から分けた仕様。ここが現在の仕様の正。仕様を変えたら、該当するファイルを更新する。

## テーマ・ヘルプ

- languageは、日本語
- ヘッダー右端のテーマのメニューから、テーマを`自動`(システム設定に追従)・`ライト`・`ダーク`・`カスタム`から選択できる。ボタンの絵が今のテーマで、メニューの選択中の項目が強調される
- `カスタム`は、primary・ヘッダーの背景(`primary に追従`も選べる)・画面の背景・文字の色・基調(ライト / ダーク)を設定できる。テーマのメニューの`カスタムの色…`でダイアログを開き、色を変えるとすぐ画面に反映する(プレビュー)。`適用`で保存し、`キャンセル`・ESC・外側クリックで開く前に戻す。基調を切り替えると、画面の背景と文字の色は、その基調の既定値に入れ替わる(primary とヘッダーの背景は残す)。`既定に戻す`は、選んでいる基調の既定値をすべて入れる(保存は`適用`)
- 今日の線の色: テーマのメニューの`今日の線の色…`で、小さなダイアログ(`#RRGGBB`の入力欄と色の選択。空欄は既定の色)を開く。色を変えるとすぐ画面に反映し(プレビュー)、`適用`で保存、`キャンセル`・ESC・外側クリックで保存済みの色に戻す。`既定に戻す`は入力欄を空にする(保存は`適用`)。不正な値は入力欄にエラーを出し、`適用`を押せなくする。色は 1 色で、設定するとライト・ダークの両方で同じ色になる(未設定は既定のまま、ダークで明るい赤)。`~/.projectapp/config.json`の`today_color`に保存する(`custom_theme`とは別のキー。`カスタム`以外のテーマでも効く。全プロジェクト共通)。ガントチャート・プレビュー・画像に反映し、PlantUML は設定があればその`#RRGGBB`、なければ`red`で塗る。線の太さは変えられない。元に戻す・やり直しの対象にしない
- 色は`#RRGGBB`のみ(不正な値は入力欄にエラーを出し、`適用`を押せなくする)。文字と画面の背景のコントラスト比が 4.5:1 を下回るとき、基調と背景の明るさが合わないときは、橙の警告を出す(適用はできる)。ヘッダーの文字は白か黒の良いほうを自動で選ぶ
- カスタムの色は`~/.projectapp/config.json`の`custom_theme`(`theme`とは別のキー。`カスタム`以外を選んでいる間も残る。全プロジェクト共通)。状態色・優先度色・土日祝の色は変えない。カスタムの色は、元に戻す・やり直しの対象にしない
- 選択したテーマは`~/.projectapp/config.json`に保存し、次回起動時に復元する
- ヘッダーの`ヘルプ`メニューの`ショートカットヘルプ`から、キー操作の一覧をいつでも確認できる
- ガントチャートの名前の欄(左の列)の幅は、名前の欄の右端(チャートとの境目)をドラッグして、120〜480px の範囲で変えられる(既定は 200px)。右端のダブルクリックで既定へ戻る。選んだ幅は`~/.projectapp/config.json`に保存し、次回起動時に復元する(全プロジェクト共通)。プレビューでは変えられず、保存した幅で表示する
