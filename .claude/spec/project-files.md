# 起動・基準日・プロジェクトファイル・保存先

> `CLAUDE.md` から分けた仕様。ここが現在の仕様の正。仕様を変えたら、該当するファイルを更新する。

## 起動時

- アプリ起動時に、格納先のプロジェクトファイルを走査する(開くのは選んだときだけ。詳細は「プロジェクトファイル」)
- 祝日データのキャッシュがない初回のみ、起動時に自動取得する。失敗しても画面は変えず、通知だけ出す

## 元に戻す・やり直し

- 編集(タスク・セクション・設定・メンバー・パラメータ・カテゴリ・URL テンプレート・イベント)を、`Ctrl/Cmd+Z` で元に戻し、`Ctrl/Cmd+Shift+Z` でやり直せる。履歴は 50 件で、アプリを閉じると消える
- 保存しても履歴は残る。保存した内容まで戻すと「未保存」の扱いが消え、それより前へ戻すと未保存に戻る
- 別のプロジェクトを開く・新規作成・PlantUML の取り込み・プルでの読み直し・`名前をつけて保存`では、履歴を捨てる(名前のない新規プロジェクトの最初の保存も、名前を付ける保存なので捨てる。2 回目以降の上書き保存は捨てない)
- ダイアログ・プレビュー・ダッシュボードの表示中と、入力欄にフォーカスがあるときは効かない。折りたたみ・絞り込み・スクロールは、元に戻さない(折りたたみは、元に戻す・やり直しのあとも同じセクションに付いたままにする。戻した状態にないセクションの分は捨てる)

## 基準日

- プロジェクト開始日と読み替えてもよい(PlantUML の`Project starts`に当たる)
- 新しいプロジェクトの既定は「今日」。設定ダイアログの`基準日(プロジェクト開始日)`で変えられる(`10/15`・`1015`・`20261015`でも書ける。過去の日も、タスクより後ろの日も可。年は 2000〜2100)。ドラッグでは基準日より前へバーを動かさない(基準日より前にあるタスクは、表示範囲に残り、右へだけ動かせる)

## プロジェクトファイル

- projectは、ファイル１枚で管理ができ、コンボボックスで切り替えができる
- プロジェクトファイルは、格納先(既定は`~/.projectapp`)の`プロジェクトの名前.json`というjsonファイルで管理できる
- 格納先は、`ファイル`メニューの`格納先を変更`で、OS のフォルダ選択から変えられる(ネイティブウィンドウのみ)。選んだ格納先は、`~/.projectapp/config.json`の`project_dir`に保存する。存在しない・フォルダでない・書き込めないフォルダは、理由を通知して変えない(空のフォルダは選べる)。変えると、ファイル一覧を読み直し、保存前の新規プロジェクトにする(編集中は、`保存して変更`・`保存せず変更`・`キャンセル`の確認ダイアログを表示する。古い格納先のファイルは動かさない)。起動時に、保存した格納先が使えないときは、通知して`~/.projectapp`で起動する(設定は書き換えない)
- projectファイルは、格納先に配置ができ、アプリ起動時にファイル走査され、見つかったprojectファイルを開けるようになる
- 起動時に見つかったファイルは、すぐに表示しない。コンボボックスで選ぶと開き、開くボタンからはファイル一覧のダイアログで選んで開く
- 編集中(保存されていない変更がある)のときは、別のプロジェクトを開く前に、`保存して開く`・`保存せず開く`・`キャンセル`の確認ダイアログを表示する
- 起動時に何も開かれていない場合は、新規ファイルとして、projectが表示されるが、projectファイルは保存されるまで配置されない
- `新規プロジェクト作成`は、起動時と同じ保存前の新規プロジェクトにする(ファイルは保存するまで作らない)。編集中は、`保存して作成`・`保存せず作成`・`キャンセル`の確認ダイアログを表示する
- `名前をつけて保存`は、名前を入力して新しいファイルに保存し、そのファイルを現在のプロジェクトにする(元のファイルは変えない。同じ名前のファイルがあれば保存しない)
- 上書き保存の直前に、読み込んだあとにファイルが外部(別のプロセス・git・同期)で変わっていないかを、内容のハッシュで調べる(更新時刻は使わない)。変わっていたら、`上書き`・`名前をつけて保存`・`キャンセル`の確認ダイアログを表示する。`上書き`は、相手の版を`<名前>.json.bak`に 1 世代退避してから保存する(退避できなければ保存しない)。ファイルが消えていたら、通知して新しく作成する。`保存して開く`・`作成`・`変更`の保存でも同じ確認を挟み、続きは保存に成功したときだけ行う

## データの保存先

- プロジェクト(メンバー・パラメータ・セクション・タスク・実績・リンク・URLテンプレート・カテゴリ・イベント・チーム・稼働設定・実績の記録方式・参照の方式・参照のスナップショット)は、格納先(既定は`~/.projectapp`)の`プロジェクトの名前.json`に1ファイルずつ保存する
- テーマと名前の欄の幅と画面の倍率とダッシュボードのビュー(`dashboard_views`〔チームは `team`〕・`dashboard_view_last`)と下部パネルの分割(`main_split`〔ガントチャートの割合 30〜100。既定 100〕・`bottom_open_ratio`〔開くときの割合 50〜90。既定 70〕)は`~/.projectapp/config.json`、祝日データのキャッシュは`~/.projectapp/holidays.json`に保存する(設定と祝日のキャッシュは、格納先を変えても`~/.projectapp`に残る。格納先は`config.json`の`project_dir`)
- 画面全体の倍率は、70〜200%(10% 刻み、既定 100%)。画面全体に CSS の `zoom` をかけるので、行の高さ・バー・矢印・文字・ダイアログがそろって変わる。全プロジェクト共通で、`config.json` の `zoom` に保存し、次回起動時に復元する。画像の書き出しの間は 100% に戻す
- 絞り込み(検索・担当者)・セクションの折りたたみ・プレビューの設定は保存しない
- 完了予定は保存しない(手で指定のときだけ入力値を保存し、それ以外は表示のたびに算出する)
