# コンセプト(仕様の全体像)

> `CLAUDE.md` から分けた仕様。ここが現在の仕様の正。仕様を変えたら、該当するファイルを更新する。

## コンセプト

- プロジェクトのタスクを`基準日`を設定しながら、管理できる
- プロジェクトに必要なリソースは、原則1人の`基準倍率`を`100%` として、その`相対比率`を、`パラメータ`を使って管理ができる
- `見積もり`については、その`人的リソース`を、`時間換算`に置き換え＋`バッファ`をつけて`日工数`に置き換える
- 見積もりのバッファについては、１日の`稼働可能時間`を設定できる（デフォルトは`6.5h`）
- `ガントチャート`の、アイテムは `コピーする`ことも`セクションごとに移動すること`も`ドラッグ`&ドロップでできる
- `ガントチャート`は、各`タスク`ごとにアイテムを設定でき、アイテムは`グループ単位`で`セクション`の形でまとめ上げることがでできる
- `ガントチャート`の`スケール`は`日次`・`週次`・`月次`と数値単位でビューを切り替えできる
- `ガントチャート`の表示は、`タスク`の`アイテム名`にて検索できそのアイテムの一番上を表示できる
- `ガントチャート`の表示は、一人担当に注目するフォーカスや、検索による絞り込みを可能とする
- ガントチャートの担当者のプルダウン(`すべての担当者`)に、メンバーのほかに`チーム: 名前`(所属するメンバーがいるチームだけ)を並べる。チームを選ぶと、そのチームのメンバーが担当に入っているタスクだけを出す(共同タスクは丸ごと。担当なしは出さない)。メンバーとチームは同時に選べない。名簿が変わると追従し、チームが消えた(メンバーがいなくなった)ら外す。保存しない
- `ガントチャート`の`スケール`は、トグルボタンで切り替えができる
- `ガントチャート`のツールバーに、表示期間の欄(スケールのトグルの右。`2026-10-01 〜 2026-10-31` の形。範囲カレンダー・省略形の整形はプレビューと同じ)を置く。空は自動(基準日とバーから決める。既定)で、入れると、その範囲だけを描き(日次は期間の日数ちょうどの列。最小の列数までは足さない。週次は月曜、月次は 1 日で区切るので、端の列は期間の外にはみ出す)、範囲外のバーは描かない。日付の軸と列は、プレビューでも同じ。欄を空にすると自動に戻る(自動のときは、これまでどおり最小の列数まで足す)。不正な入力・列数が上限を超える期間は、欄の下にエラーを出し、前の期間のままにする。スケールを変えて上限を超えるときは、期間を自動に戻して通知する。別のプロジェクトを開くと自動に戻る。保存しない。プレビューを開くときの期間の初期値は、この期間(あれば)
- `ガントチャート`の`セクション`は、見出しの矢印か名前のクリックで折りたためる。見出しにタスク件数を出す。絞り込み中は折りたたみを無視して、一致したタスクを出す
- `ガントチャート`の`セクション`は、サブセクションを持てる（セクションを最大3階層まで。タスクは`root`と、どの階層のセクションにも置ける）。サブセクションは、1・2階層目のセクションの見出しのボタンで追加する（改名・コピー・削除は、見出しの右クリックのメニューでできる。並べ替えは、見出しのドラッグでできる）。セクションの中は、タスクが先、サブセクションが後。インデントして並べ、見出しのタスク数はサブセクションの分も含めた合計。折りたたみは、サブセクションもまとめて隠し、親を開いても子の折りたたみの状態を保つ。絞り込み中は、一致したタスクの親のセクションも出す
- `セクション追加`は、ガントチャートの末尾(最後のセクションの下)の行の、名前の列の右端のボタンで行う（ツールバーにはない。プレビュー(読み取り専用)では出さない。絞り込み中も出す）。追加のボタンは、アイコンで見分ける(タスクを足す=チェックの付いた＋`add_task`、セクション・サブセクションを足す=フォルダの＋`create_new_folder`)
- `ガントチャート`のタスクには、`開始予定`、`完了予定`、`締切`、`工数`（時間単位）を設定できる
- `完了予定`は、工数があれば`開始予定`+`工数`から自動算出する（稼働可能時間と祝日を反映し、設定の変更はすぐ反映される）。`手で指定`のチェックで手入力に切り替えられる。手で指定のときも、工数があれば算出値を参考値として入力欄の上に出し、ヒントに算出値との日数差(暦日)を出す。工数がないときは直接入力し、空欄なら`締切`（なければ`開始予定`の翌日）になる
- `締切`（納期）は、日付と任意の時刻で設定でき、ガントチャートに目印（◆）で表示する
- `開始`・`終了`は、実際に作業した日時（実績）で、実績として入力できる（記録方式は下記の設定ダイアログで選ぶ）
- `メンバー`（担当者）は、プロジェクトごとに名前と`基本比率`（基準の人を100%とした作業速度の基本値）で管理する。`相対比率`は、`基本比率 + 選んだ段階の判定値の合計`で決まり、50〜150%に丸めて使う（丸めたときは、メンバーの画面に示す。基本比率の入力・読込の範囲は 10〜300% のまま。メンバーごとの`丸めない`〔`メンバーとパラメータ`のメンバーの表のチェック〕をオンにすると、その人の相対比率は既定の 50〜150% や設定の上限・下限で丸めず、`基本比率 + 判定値の合計`を使う。固定の 10〜300% だけは常に守り、掛かったときは注記を出す。見直し確認は出さない）。メンバーごとに`警告の件数`(閾値。整数 1〜999、空は閾値なし。メンバーの表の列)を持てる。ダッシュボードの`進捗と遅れ`で、警告のタスクの件数がこの数以上のメンバーを強調する
- `メンバー`には`アイコン`（画像ファイル。Slack のアイコンなど）を設定でき、設定されていれば、ガントチャートの担当者チップ・ダッシュボードの人ごとの負荷・プレビュー・画像に出す（なければ頭文字）。取り込むのは PNG・JPEG・GIF・WebP（10MB まで。SVG は不可）で、中央を正方形に切り抜いて 128×128 の PNG に縮め、プロジェクトのファイルに埋め込む。画像を選ぶのはネイティブウィンドウのみ（外すのはどこでもできる）。担当者向けファイルと PlantUML には出さない
- `メンバー`には`稼働日の上書き`を持たせられる(`メンバーとパラメータ`のメンバーの表の`稼働日`ボタン)。日付ごとに、稼働の時間帯(開始〜終了。同じ日の 23:59 まで。日付はカレンダー、時刻は時刻選択でも入力できる)か休みを 1 日ずつ登録でき、本来休みの日(土日祝)にその人だけ稼働したり、平日を休みにできる。上書きした日は、その人の枠を丸ごと置き換える(土日祝の判定より優先)。日付は昇順に並べ、重複は不可。上書きがなければ今までと同じ。各日にメモ(30 文字以内。理由。例: 夏季休暇)を付けられる。稼働日のダイアログの`期間で追加`で、期間(範囲カレンダー可)の各日を 1 日ずつの行にまとめて足せる(休み / 稼働の時間帯。`土日祝を除く`は既定オン。登録済みの日は上書きせず飛ばす。1 回 366 日まで)。ホバー(ガントチャートの橙の印)にメモを添える(`休み(夏季休暇)`)
- `チーム`は、プロジェクトごとに名前(30 文字以内。タスク名と同じ文字の制限。同じ名前・空は不可)で登録する(`プロジェクト`メニューの`メンバーとパラメータ`の`チーム`タブ)。メンバーは複数のチームに所属でき(兼務)、チームごとに所属の割合(整数 1〜100%)を持つ。チームに入っているメンバーは、割合の合計をちょうど 100% にする(1 つだけなら 100%。チームなしも可)。メンバーの表の`チーム`列(チームが 1 つ以上あるときだけ)のボタンで、チェックと割合を入れる(2 つ以上のときだけ割合を出し、チェックを足し引きすると均等割りから始める)。チームの削除は、所属するメンバーがいるとき確認(人数)を出し、その所属を外して残りの割合を比を保って 100% に揃える(端数は最大の所属、同じなら先頭)。タスクにチームは記録しない。ガントチャートとダッシュボードの絞り込みに使える(下記)。集計の按分は下記(ダッシュボード)
- タスクの編集ダイアログの`担当`の節に、所属するメンバーがいるチームがあるときだけ`チームから追加`(チームの選択・割り当て率・`追加`)を出す。押すと、そのチームのメンバーを担当者として加える(いる人は割り当て率だけ更新する。その時点のメンバーを展開するだけで、あとでチームの名簿が変わってもタスクは変わらない)。週ごとの担当のタスクでは、担当の欄と一緒に隠す
- `パラメータ`は、プロジェクト共通で、`プロジェクト`メニューの`メンバーとパラメータ`の`パラメータ`タブで、名前と段階（名前と判定値-90〜+290%）を登録する。メンバーは、パラメータごとに段階を選ぶ（選ばなければ判定値0%）。パラメータ・段階の改名は、メンバーの選択に引き継ぐ。削除は、その段階を選んでいるメンバーがいるとき、またはそのパラメータを付けたタスクがあるときに確認を出し、選択を外す（メンバーは判定値0%、タスクはパラメータなしになる）。相対比率(基本比率 + 判定値の合計)そのものに、プロジェクトの設定で下限・上限を設けられる(既定は 50〜150%。設定では、この範囲の中で狭められる。例: 下限 80%・上限 120%。下限・上限とも 50〜150% で、下限は上限以下。空欄は設定なしで既定のまま。プリセット `50% 〜 150%`)。基本比率だけのメンバーにも掛かるので、基本比率の入力値より結果が変わることがある(基本 200% は既定の上限 150% で 150%、基本 30% は既定の下限 50% で 50%)。付けたパラメータだけを数えるタスクにも同じ制限が掛かる。換算率の内訳とメンバーの画面に、制限したときだけ注記を出す(例: 相対比率 250% → 上限 150% に制限)
- タスクには、登録した`パラメータ`を複数付けられる(編集ダイアログの`担当・パラメータ`の節の`パラメータ`欄。登録がなければ欄を出さない。ガントチャートのチップには出さない)。付けたタスクでは、担当メンバーの相対比率が`基本比率 + 付けたパラメータの判定値の合計`(付けなかったパラメータは数えない。選んでいない段階は判定値0%。50〜150%に丸める)になり、完了予定・ダイアログの換算率・担当者向けファイルの見積もりがその値を使う。付けないタスクは今までどおり全パラメータの合計。パラメータの改名はタスクの選択に引き継ぐ。タスクのコピーと分解の子は、付けたパラメータを引き継ぐ(まとめ・チェックポイントは持たない)
- タスクには複数の担当者を割り当てられる。担当者ごとに、`メンバー`から選び、そのタスクに使う`割り当て率`（担当者の時間の1〜100%）を設定する。同じメンバーは1つのタスクに1回まで
- 工数（時間）は、基準の人が全時間をかけた場合の時間とし、`工数 ÷ 担当者全員の（相対比率 × 割り当て率）の合計`（相対比率は、パラメータを反映した値）を稼働可能時間（バッファ）の枠に割り当てて`完了予定`を算出する（複数の担当者は共同作業とみなし、合計で割るので完了が早まる）。ダイアログには日数に換算した値と、換算率の内訳を表示する。担当者が複数で稼働の枠が違う日は、全員の枠を時刻で重ね、その時刻に稼働している担当者の換算率の合計で工数を消化する(上書きがなければ、全員が同じ枠なので、工数 ÷ 換算率の合計と同じ)。担当者のいないタスクは、通常のカレンダー(月〜金・祝日を除く)で算出する
- タスクの担当者は、`週ごとに分ける`で、開始の日から 7 日(暦日)ごとの週ごとに変えられる。始めるのは、ガントチャートのタスクの行の右クリックメニューの`週ごとに分ける`(担当者がいる通常タスク。今の担当が、開始予定から完了予定までの全部の週に入る。日付が読めなければ第1週だけ。週数の上限は 52)で、戻すのは同じメニューの`週ごとをやめる`(第1週の担当が全期間の担当に戻る)。週ごとの担当は、タスクの編集ダイアログでは直さない(担当の欄に代わりに説明を出す)。新規作成のダイアログにもない。各週に担当者が最低 1 人で、割り当て率は週ごとに持つ。週は先行による押し出しを反映した実効の開始から数え、最後の週の担当はその後も続く。完了予定は、その日の担当者の換算率の合計で工数を消化して算出する(週ごとに分けないタスクは今までどおり)。割り当て超過・ダッシュボードの負荷と予定工数・担当者向けファイルの見積もりも、週ごとの担当で数える。`assignees`は全週の和集合(割り当て率は各人の最大値)で、名前の欄のチップはこれを使う。ガントチャートの棒の上には、週ごとの担当のチップを重ねる(日次・週次は幅があれば頭文字、月次は区切りだけ。表示項目のチップに従う)。棒は、定義した週より後も 7 日ごとにチップで区切り、担当は最後の週のものが続く。割り当て超過のヒントは、チップの行より下の領域に出し、チップの上ではチップのヒントに負荷の説明を足す(2 つが重ならないように)。週のチップのホバーは、1 行目に`第N週 9/21〜9/27`(定義した週より後は`(第N週の担当が続く)`を添える)、2 行目から担当と割り当て率、その週にかかる超過があれば`⚠ 田中 最大120%`の行を出す(超過の説明は`の割り当て`と書かず、期間はチップの見出しにあるので付けない)。名前の欄の担当者チップのホバーは、普通はその人の割り当て率(`田中 100%`)と案内(`Shift: 週ごとの担当`)だけを出し、Shift を押している間だけ、週ごとの担当を各週の行に期間を添えて出す(`第1週 10/5〜10/11: 田中 100%`。週ごとに分けないタスクは案内も出さない。Shift の判定は、画面全体で押下を追って body に印を付け、CSS で出し分ける)。棒全体の超過のヒントは`田中 最大120%(10/7〜10/9)`の形。ホバーの担当者と、割り当て超過のヒントの担当者ごとの説明は 3 人ごとに改行する。チップは割り当て超過の縞より前に出し、文字に黒い縁を付ける。日次・週次で幅が足りるとき、アイコンのあるメンバーは頭文字の代わりに小さな丸い画像(10px)で出す。チップを左クリックすると、その週の担当と割り当て率だけを直す小さなダイアログ(タイトルはホバーの見出しと同じ`第N週 9/21〜9/27`)を開く(定義した週より後のチップなら、間の週を直前の週のコピーで足してから直す。保存で和集合も整える。プレビューでは開かない)。週ごとのタスクは、担当の付け替え時の見直し確認の対象外。分解はできるが、週ごとの担当は子に引き継がれない(下の「タスクの分解」)。PlantUML は和集合・各人の最大の割り当て率で出し、近似であることを通知する。3 者マージは`weekly_crew`をリスト全体で 1 項目として比べ、消えたメンバーで空になった週は隣の週と同じにして通知する
- 人的リソース1人に対して、project内で、最大`100%`まで分散できる
- 同じ担当者の、期間が重なるタスクの`割り当て率`の合計（複数の担当者のタスクは、担当者ごとの割り当て率を、その担当者の合計に数える）が100%を超える期間は、ガントチャートの棒の内側に縞で示し、保存時に通知する（保存はできる。状態が「終了」のタスクは数えない）
