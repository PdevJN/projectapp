# 稼働日の上書き(要望 30) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 日付ごとに稼働の時間帯(開始〜終了)または休みを登録し、完了予定の算出・ダッシュボード・ガントチャート・PlantUML・マージに反映する。

**Architecture:** `Project.work_days: list[WorkDay]` を足し(`FORMAT_VERSION` 8)、`timeline.day_window()` が日ごとの枠を返す。`_calc_end` などはその枠で回す。`holidays` の経路は変えず、`work_days` は `Mapping[date, WorkDay]` を末尾の省略可能な引数として渡す。設定ダイアログは「イベント」の節と同じ作りで足す。

**Tech Stack:** Python 3.13、NiceGUI、pytest(`nicegui.testing.User`)、ty、uv。

**Spec:** `docs/superpowers/specs/2026-10-22-work-days-design.md`

## Global Constraints

- すべての関数に型ヒント(引数・戻り値)を付ける。型は `uv run ty check src/projectapp` で検証し、指摘を増やさない。
- コメントは多くても 3 行以内。PEP8。言語は日本語(コメント・通知・ドキュメント)。
- `FORMAT_VERSION` は 8。`work_days` のないファイル(version 7 以下)は空として読む。version 8 で不正な値は読込を拒否する。
- 終了時刻は同じ日の 23:59 まで(24:00 は扱わない)。休みは `start`・`end` がともに `None`。同じ日付は 1 件まで。年は 2000〜2100。
- 上書きした日は、その日の枠を丸ごと置き換える(祝日・土日の判定より優先)。
- 上書きがなければ、結果は今までと完全に同じ(既存テストが通る)。
- テストは `test/`。実行は `uv run pytest test/<file> -q`、全体は `uv run pytest -n auto -q`。
- コマンドは `&&` でつなぐ。ブランチは `feature/work-days`。コミット末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` を付ける。

## Review Focus

- 土曜に 13:00〜16:00 を登録したとき、金曜の枠に収まらない工数がちょうど土曜 13:00 から繰り越される(日付またぎの境界)。
- 開始予定が枠の「前」「途中」「終了ちょうど」「後」のそれぞれで、完了予定がずれない。
- 祝日を稼働に上書きしたとき、算出に使われる。平日を休みにすると飛ばされる。
- 上書きのない既存プロジェクトでは、完了予定・予定工数・負荷・PlantUML が 1 文字も変わらない。
- 全プロジェクトの負荷で、1 つのプロジェクトだけが土曜を稼働にした日も列に出る(他のプロジェクトでは負荷 0)。
- 設定ダイアログで、日付の重複・開始 ≥ 終了・不正な時刻・片方だけ空の入力は、適用されずエラーになる。休みにチェックを入れると開始・終了は無視される。
- version 7 のファイルを開いて保存し直すと、`work_days: []` を持つ version 8 になる。

```python
"""稼働日の上書きの規則(検証・並べ替え・辞書化)。NiceGUI に依存しない。"""

from collections.abc import Iterable
from datetime import date

from projectapp.models import MAX_YEAR, MIN_YEAR, WorkDay


def validate_work_days(days: list[WorkDay]) -> None:
    """日付が重複しない・年が範囲内・休みか(開始 < 終了)のどちらか。不正は ValueError。"""
    seen: set[date] = set()
    for row in days:
        if not MIN_YEAR <= row.day.year <= MAX_YEAR:
            raise ValueError(f"稼働日の日付は {MIN_YEAR}〜{MAX_YEAR} 年にしてください: {row.day.isoformat()}")
        if row.day in seen:
            raise ValueError(f"稼働日の日付が重複しています: {row.day.isoformat()}")
        seen.add(row.day)
        if (row.start is None) != (row.end is None):
            raise ValueError(f"稼働日の開始と終了は、両方入れるか休みにしてください: {row.day.isoformat()}")
        if row.start is not None and row.end is not None and row.start >= row.end:
            raise ValueError(f"稼働日の終了は開始より後にしてください: {row.day.isoformat()}")


def sort_work_days(days: list[WorkDay]) -> list[WorkDay]:
    return sorted(days, key=lambda row: row.day)


def work_day_map(days: Iterable[WorkDay]) -> dict[date, WorkDay]:
    """日付 → 上書き。"""
    return {row.day: row for row in days}
```

```python
def _work_days(value: Any) -> list[WorkDay]:
    """稼働日の上書き(version 8)。キーがない・null は空。形・時刻・重複の不正は ValueError。"""
    if value is None:
        return []
    if not isinstance(value, list):
        raise ValueError("稼働日の上書きがリストではありません")
    rows: list[WorkDay] = []
    for raw in value:
        if not isinstance(raw, dict):
            raise ValueError("稼働日の上書きの形式が正しくありません")
        day = _iso_date(raw.get("day"), "日付")
        times: list[time | None] = []
        for key in ("start", "end"):
            text = raw.get(key)
            if text is None:
                times.append(None)
            elif isinstance(text, str):
                try:
                    times.append(time.fromisoformat(text))
                except ValueError:
                    raise ValueError(f"稼働日の{key}の形式が正しくありません: {text!r}") from None
            else:
                raise ValueError(f"稼働日の{key}が文字列ではありません: {text!r}")
        rows.append(WorkDay(day, times[0], times[1]))
    validate_work_days(rows)
    return sort_work_days(rows)
```

- `parse_project` の `events=...` の次に `work_days=_work_days(raw.get("work_days")) if ctx.version >= 8 else [],` を足す。
- `_iso_date` のエラー文は `イベントの{label}` を含む。稼働日でも読めるよう、`_iso_date(text, label)` のメッセージの先頭の `イベントの` を `` にして `{label}が YYYY-MM-DD ではありません` にするのではなく、**既存のテストを壊さないため**、`_iso_date` はそのままにして、`_work_days` では `try: _iso_date(...) except ValueError as exc: raise ValueError(str(exc).replace("イベントの", "稼働日の")) from None` で包む。

`_dump`(`storage.py:104`)は `asdict(project)` を使うので、`work_days` は自動で `{"day", "start", "end"}` の辞書になり、`_encode` が `date`・`time` を ISO 文字列にする。保存時に日付の昇順に並べるため、`_dump` の `data` を作る行の直後に `data["work_days"] = [asdict(w) for w in sort_work_days(project.work_days)]` を足す(`default=_encode` が文字列にする)。

```python
def _default_open(day: date, holidays: dict[date, str]) -> bool:
    """上書きがないときの稼働日: 月〜金で祝日でない日。"""
    return day.weekday() < 5 and day not in holidays


def is_workday(day: date, holidays: dict[date, str], work_days: Mapping[date, WorkDay] | None = None) -> bool:
    """稼働日か。稼働日の上書きがあればそれ(休みは稼働日でない)、なければ月〜金で祝日でない日。"""
    if work_days and day in work_days:
        return work_days[day].start is not None
    return _default_open(day, holidays)


def day_window(
    day: date,
    daily_hours: float,
    work_start: time,
    holidays: dict[date, str],
    work_days: Mapping[date, WorkDay] | None = None,
) -> tuple[datetime, datetime] | None:
    """その日の稼働の枠(開始, 終了)。枠がない日(休み・土日祝)は None。上書きがあれば、その日の枠を置き換える。"""
    if work_days and day in work_days:
        row = work_days[day]
        if row.start is None or row.end is None:
            return None
        return datetime.combine(day, row.start), datetime.combine(day, row.end)
    if not _default_open(day, holidays):
        return None
    opens = datetime.combine(day, work_start)
    return opens, opens + timedelta(hours=daily_hours)


def day_hours(
    day: date,
    daily_hours: float,
    holidays: dict[date, str],
    work_days: Mapping[date, WorkDay] | None = None,
) -> float:
    """その日の稼働時間[h]。枠がなければ 0。"""
    window = day_window(day, daily_hours, time.min, holidays, work_days)
    return (window[1] - window[0]).total_seconds() / 3600 if window else 0.0


def calc_end(
    start: datetime,
    effort_hours: float,
    daily_hours: float,
    work_start: time,
    holidays: dict[date, str],
    work_days: Mapping[date, WorkDay] | None = None,
) -> datetime | None:
    """日ごとの稼働の枠(既定は始業から連続daily_hours時間。稼働日の上書きがあればその枠)に工数を割り当てた終了日時。

    工数が不正(NaN・inf・0以下・稼働日数の上限超え)、daily_hoursが0以下・24超、
    または日付が範囲を超えるときは、例外にせずNoneを返す。
    """
    if not isfinite(effort_hours) or effort_hours <= 0 or not 0 < daily_hours <= 24:
        return None
    if effort_hours > daily_hours * MAX_WORKDAYS:
        return None
    try:
        return _calc_end(start, effort_hours, daily_hours, work_start, holidays, work_days)
    except OverflowError:
        return None


def _calc_end(
    start: datetime,
    effort_hours: float,
    daily_hours: float,
    work_start: time,
    holidays: dict[date, str],
    work_days: Mapping[date, WorkDay] | None,
) -> datetime:
    remaining = timedelta(hours=effort_hours)
    day, cursor = start.date(), start
    while True:
        window = day_window(day, daily_hours, work_start, holidays, work_days)
        if window is not None:
            begin = max(cursor, window[0])
            if begin < window[1]:
                available = window[1] - begin
                if remaining <= available:
                    return begin + remaining
                remaining -= available
        day += timedelta(days=1)
        cursor = datetime.combine(day, time.min)
```

class WorkDayRow:
    day: str

def build_work_day_list(rows: list[WorkDayRow], today: date) -> list[WorkDay]:
    """入力の行を検証して、日付の昇順の一覧にする。完全に空の行は無視する。休みの行は時刻を見ない。"""
    built: list[WorkDay] = []
    for row in rows:
        if not row.rest and not any(t.strip() for t in (row.day, row.start, row.end)):
            continue
        day = parse_date_input(row.day, today, roll_forward=False)
        if day is None:
            raise ValueError("稼働日の日付を入力してください(例: 2026-10-17、10/17)")
        if row.rest:
            built.append(WorkDay(date.fromisoformat(day)))
            continue
        start, end = parse_time_input(row.start), parse_time_input(row.end)
        if start is None or end is None:
            raise ValueError(f"稼働日 {day} の開始と終了を時刻で入力してください(例: 13:00、930)。休みなら「休み」にチェックしてください")
        built.append(WorkDay(date.fromisoformat(day), time.fromisoformat(start), time.fromisoformat(end)))
    validate_work_days(built)
    return sort_work_days(built)


def work_day_key(w: WorkDay) -> tuple:
    return (w.day, w.start, w.end)

2. 日次スケールで、その土曜の背景が平日と同じになり、日付ヘッダーの下端に橙の印が付く。マウスオーバーに`稼働 13:00〜16:00`。週次・月次では出ない。
3. 平日を休みにすると、その日が灰色になり、完了予定が後ろにずれる。祝日を稼働にすると算出に使われる。
4. 休みにチェックを入れると開始・終了が入力できなくなる。日付の重複・開始 ≥ 終了・時刻の欠けはエラーになる。
5. `Cmd+Z` で適用前に戻り、やり直しもできる。保存して開き直しても残る。
6. ダッシュボード: 「工数の予定と実績」の予定が土曜 3h ぶん増える。全プロジェクトをオンにしたヒートマップに、稼働にした土曜の列が出る。
7. プレビューと PlantUML 保存: チャートに上書きが反映され、PlantUML に`is open`・`is closed`が出る。
8. ダークテーマで橙の印と灰色の背景が見える。上書きがないプロジェクトの見た目・完了予定が変わっていない。
