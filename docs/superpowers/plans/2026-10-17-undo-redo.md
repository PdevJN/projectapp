**Goal:** 保存前の編集(プロジェクト全体)を、`Ctrl/Cmd+Z` で元に戻し、`Ctrl/Cmd+Shift+Z` でやり直せるようにする。

**Architecture:** `Project` の複製を積む履歴クラス(`history.py`。NiceGUI に依存しない)を足す。編集の入口 12 か所の `gantt.set_project(self.project)` を `after_edit()` に集約し、直前の状態と比べて変わっていれば履歴に積む。入力欄での誤爆は、NiceGUI の `ui.keyboard` が初期設定で入力欄のイベントを無視することを使い、Undo/Redo を「入力欄を無視する側」のハンドラーで受けて避ける。

**Tech Stack:** Python 3.13、NiceGUI、pytest(`uv run pytest`)

**Spec:** `docs/superpowers/specs/2026-10-17-undo-redo-design.md`

## Global Constraints

- 言語は日本語。UI の文言・コメント・docstring は日本語(既存のコードに合わせる)。
- Python 3.13 以上。外部ライブラリは足さない(`copy.deepcopy`・`collections.deque` を使う)。
- 履歴の上限は 50 件。
- 履歴に積むのは `Project` の複製(`deepcopy`)。履歴が持つ物と、画面が持つ物は、同じオブジェクトを指さない。
- 通知の文言: `元に戻しました` / `やり直しました` / `これ以上戻せません` / `やり直す操作がありません`。
- ショートカット: `Ctrl/Cmd+Z` = 元に戻す(`undo`)、`Ctrl/Cmd+Shift+Z` = やり直す(`redo`)。ダイアログ・プレビュー・ダッシュボードの表示中は効かない。入力欄にフォーカスがあるときは効かない(ブラウザ標準の文字の取り消しに任せる)。
- ヘッダーにメニューは足さない(「メニュー 5 つ」の仕様を守る)。
- 履歴を破棄する場面: `show_project`(開く・新規作成・PlantUML 取り込み・プル後の読み直しが通る)、`save_as_new` の成功時(`名前をつけて保存`と、保存前の新規プロジェクトの最初の保存。どちらもプロジェクト名が変わる)。2 回目以降の上書き保存では破棄しない。
- テストは `uv run pytest`。並列は `uv run pytest -n auto`。実際の `~/.projectapp` を読み書きしない(`tmp_path` を使う)。
- コミットメッセージは日本語の `feat:`/`test:`/`docs:` で始め、末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` を付ける。ブランチは git-flow に従い、`develop` から `feature/undo-redo` を切る。

## Review Focus

- 入力欄(検索欄)で `Ctrl/Cmd+Z` を押しても、プロジェクトの編集が戻らないこと(Task 2・3 の `test_..._ignored_in_inputs` と JS のハーネスで固定)。

```python
"""元に戻す・やり直しの履歴(NiceGUI に依存しない)。プロジェクトの複製を積む。"""

from collections import deque
from copy import deepcopy

from projectapp.models import Project

HISTORY_LIMIT = 50


class History:
    """変更の直前の状態(Undo)と、戻した側の状態(Redo)を持つ。どちらも複製で持ち、上限を超えたら古い物から捨てる。"""

    def __init__(self, limit: int = HISTORY_LIMIT) -> None:
        self.undo_stack: deque[Project] = deque(maxlen=limit)
        self.redo_stack: deque[Project] = deque(maxlen=limit)

    def record(self, before: Project) -> None:
        """変更の直前の状態を積む。新しい編集なので、Redo は空にする。直前に積んだ物と等しければ積まない。"""
        self.redo_stack.clear()
        if self.undo_stack and self.undo_stack[-1] == before:
            return
        self.undo_stack.append(deepcopy(before))

    def undo(self, current: Project) -> Project | None:
        """いまの状態を Redo に積み、直前の状態を返す。戻せなければ None(何も変えない)。"""
        if not self.undo_stack:
            return None
        self.redo_stack.append(deepcopy(current))
        return self.undo_stack.pop()

    def redo(self, current: Project) -> Project | None:
        """いまの状態を Undo に積み、やり直す状態を返す。やり直せなければ None(何も変えない)。"""
        if not self.redo_stack:
            return None
        self.undo_stack.append(deepcopy(current))
        return self.redo_stack.pop()

    def clear(self) -> None:
        self.undo_stack.clear()
        self.redo_stack.clear()

    def can_undo(self) -> bool:
        return bool(self.undo_stack)

    def can_redo(self) -> bool:
        return bool(self.redo_stack)
```

```python
def defers_to_inputs(key: str, ctrl: bool) -> bool:
    """押されたキーが、入力欄のあいだは入力欄に任せる割り当て(`in_inputs=False`)か。"""
    key = key.lower()
    return any(
        not s.in_inputs and s.ctrl == ctrl and key in (s.key, *s.aliases) for s in SHORTCUTS
    )


def input_owned_keys() -> set[str]:
    """入力欄のあいだは入力欄に任せる、Ctrl/Cmd と組み合わせるキー。"""
    return {k for s in SHORTCUTS if s.ctrl and not s.in_inputs for k in (s.key, *s.aliases)}
```

```python
def key_guard_js() -> str:
    """割り当てたキーの既定の動き(`Ctrl+S` の保存・`Ctrl+P` の印刷、macOS の警告音)を止める JS。
    文字キーは、入力欄の中では止めない。ESC は文字でないので、入力欄でも止める(変換中の ESC は、変換の取り消しなので止めない)。
    `Ctrl/Cmd+Z` は入力欄では文字の取り消しなので、入力欄の中では止めない。"""
    return (
        "document.addEventListener('keydown', e => {"
        f" const ctrl = {sorted(ctrl_keys())!r}, plain = {sorted(plain_keys())!r}, owned = {sorted(input_owned_keys())!r};"
        " const key = e.key.toLowerCase(), t = e.target || {}, tag = (t.tagName || '').toLowerCase();"
        " const editable = ['input', 'textarea', 'select'].includes(tag) || t.isContentEditable === true;"
        " const typing = editable && !(key === 'escape' && !e.isComposing);"
        " const held = e.ctrlKey || e.metaKey;"
        " if (held ? ctrl.includes(key) && !(editable && owned.includes(key)) : plain.includes(key) && !typing) e.preventDefault();"
        " }, true);"
    )
```

```python
    def after_edit(self) -> None:
        """編集のあとの共通の処理。直前の確定した状態と違えば履歴に積み、画面を描き直す(Undo の入口はここだけ)。"""
        if self.project != self.committed:
            self.history.record(self.committed)
            self.committed = deepcopy(self.project)
        self.gantt.set_project(self.project)

    def reset_history(self) -> None:
        """履歴を捨て、いまの内容を確定した状態にする(別のプロジェクトに切り替えたとき・名前をつけて保存したとき)。"""
        self.history.clear()
        self.committed = deepcopy(self.project)

    def restore(self, project: Project) -> None:
        """Undo・Redo で取り出した状態に差し替えて描き直す。折りたたみ・絞り込み・スクロールは、プロジェクトの外なので変えない。"""
        self.project = project
        self.committed = deepcopy(project)
        self.gantt.set_project(self.project)

    def undo(self) -> None:
        restored = self.history.undo(self.project)
        if restored is None:
            ui.notify("これ以上戻せません")
            return
        self.restore(restored)
        ui.notify("元に戻しました")

    def redo(self) -> None:
        restored = self.history.redo(self.project)
        if restored is None:
            ui.notify("やり直す操作がありません")
            return
        self.restore(restored)
        ui.notify("やり直しました")
```
