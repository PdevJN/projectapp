# 複数タスクの一括編集・一括削除 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ガントチャートで複数のタスクを Cmd/Ctrl・Shift クリックで選び、担当・カテゴリ・完了予定・工数をまとめて変え、まとめて削除できるようにする(要望 35)。

**Architecture:** 選択(`bulk_select.py`)と編集・削除(`bulk_edit.py`)は NiceGUI に依存しない純粋関数にする。`apply_bulk` はプロジェクトを変えず、変更後のタスクを返す(ダイアログの見込みはこのドライランを使う)。画面は `gantt.py` に選択の受け口・選択バー・右クリックの項目を足し、`bulk_dialog.py` と `MainView` の配線で適用する。適用 1 回 = `after_edit()` 1 回 = Undo 1 ステップ。ファイル形式は変えない。

**Tech Stack:** Python 3.13、NiceGUI、pytest(`uv run pytest`)、`uv run ty check src`、Node(JS の構文・動きの確認)。

**Spec:** [`docs/superpowers/specs/2026-10-29-bulk-edit-design.md`](../specs/2026-10-29-bulk-edit-design.md)

## Global Constraints

- ファイル形式は変えない。`FORMAT_VERSION`(16)は据え置き。
- 選択は保存しない。元に戻す・やり直しの対象にしない。プロジェクトを開き直す・`名前をつけて保存`・格納先の変更で解除する。
- 修飾なしのクリックは今と同じ(何も起きない)。選択の解除は `Esc` と選択バーの`解除`だけ。
- 行の要素を増やさない(要望 24)。行に足すのは属性 `data-task-id` とクラス `task-selected` だけ。`render.refresh()` は選択のために呼ばない。
- 対象の種別: 担当・完了予定・工数=通常のみ。カテゴリ=通常・まとめ・チェックポイント。プロジェクト参照はどれもスキップ。
- 担当の第 N 週以降: N は 2〜`MAX_WEEKS`(52)。割り当て率は 1〜100%。完了予定のずらしは ±1〜365 日。
- 完了予定は日付指定でもずらしでも `planned_end_manual = True`。日付指定の時刻は `日付 + work_start + daily_hours`(CSV 取り込みと同じ)。
- 工数は小数点以下 2 桁(`effortunits.DECIMALS`)。単位は時間・日・週・月(`effortunits.to_hours`)。
- 画面の文言は日本語、識別子は英語、コメントは周囲に合わせて日本語。テストは `test/`(`tests` ではない)。
- 作業ブランチは `feature/bulk-edit`(`develop` から切る)。コミットメッセージの末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`。

## Review Focus

- 絞り込みで隠れた行は、選択済みでも編集・削除の対象にならない(Task 1 の `effective`、Task 5 の画面テスト)。
- まとめを選ぶと隠れた子も入り、子だけを外せる。まとめと子が一緒に削除され、先行リンクが整理される(Task 1、Task 3 の削除)。
- 工数の増減で 0 未満になる・工数がないタスクと、完了予定が開始予定より前になるタスクは、スキップされて件数に出る。元は変わらない(Task 2)。
- 担当の削除で空になる週は隣の週と同じにし、全週が空なら週ごとをやめて担当なしにする。置き換えは週ごとを解除し、件数を数える(Task 3)。
- 適用は Undo 1 回で戻り、Undo や削除でなくなった id は選択から落ちる。ドライランは元のプロジェクトを変えない(Task 2・3・5)。

```python
"""複数タスクの一括操作の選択。NiceGUI に依存しない。タスクの id で持つ(行の位置は編集で変わるため)。"""

from collections.abc import Mapping, Sequence
from dataclasses import dataclass, field

from projectapp.models import Task, TaskKind


def with_children(task_id: str, by_id: Mapping[str, Task]) -> list[str]:
    """task_id と、まとめなら子(by_id にあるもの)。task_id が by_id になければ空。"""
    task = by_id.get(task_id)
    if task is None:
        return []
    if task.kind is TaskKind.SUMMARY:
        return [task_id, *(cid for cid in task.children if cid in by_id)]
    return [task_id]


@dataclass
class BulkSelection:
    ids: set[str] = field(default_factory=set)
    anchor: str | None = None  # Shift クリックの基点(最後に Cmd/Ctrl クリックした行)

    def toggle(self, task_id: str, by_id: Mapping[str, Task]) -> None:
        """Cmd/Ctrl クリック。まとめなら子もまとめて入れる・外す。基点を動かす。"""
        group = with_children(task_id, by_id)
        if not group:
            return
        if task_id in self.ids:
            self.ids.difference_update(group)
        else:
            self.ids.update(group)
        self.anchor = task_id

    def extend(self, visible_ids: Sequence[str], task_id: str, by_id: Mapping[str, Task]) -> None:
        """Shift クリック。見えている行の中で、基点と task_id の間を加える。基点が使えなければ toggle と同じ。"""
        if self.anchor not in visible_ids or task_id not in visible_ids:
            self.toggle(task_id, by_id)
            return
        first, last = sorted((visible_ids.index(self.anchor), visible_ids.index(task_id)))
        for tid in visible_ids[first : last + 1]:
            self.ids.update(with_children(tid, by_id))

    def effective(self, visible_ids: Sequence[str]) -> list[str]:
        """適用の対象。見えている行だけを、描画順で返す(絞り込みで隠れた行は含めない)。"""
        return [tid for tid in visible_ids if tid in self.ids]

    def prune(self, by_id: Mapping[str, Task]) -> None:
        """削除や Undo でなくなった id を落とす。"""
        self.ids.intersection_update(by_id.keys())
        if self.anchor not in by_id:
            self.anchor = None

    def clear(self) -> None:
        self.ids.clear()
        self.anchor = None
```

```python
"""複数タスクの一括編集。NiceGUI に依存しない。apply_bulk は project を変えず、変更後のタスクを返す。"""

from collections import Counter
from collections.abc import Collection, Sequence
from dataclasses import dataclass, field, replace
from datetime import date, datetime, timedelta
from enum import Enum

from projectapp.effortunits import DECIMALS
from projectapp.models import MAX_YEAR, MIN_YEAR, Assignee, Project, Task, TaskKind, walk_sections
from projectapp.timeline import Schedule, own_end

SKIP_KIND = "対象外の種別"
SKIP_NO_CREW = "担当なし"
SKIP_NO_START = "開始予定なし"
SKIP_BEFORE_START = "開始予定より前"
SKIP_NO_END = "完了予定が読めない"
SKIP_NO_EFFORT = "工数なし"
SKIP_NEGATIVE = "工数が 0 未満"
SKIP_RANGE = "日付が範囲外"

CATEGORY_KINDS = (TaskKind.NORMAL, TaskKind.SUMMARY, TaskKind.CHECKPOINT)


class CrewMode(Enum):
    ADD = "追加"
    REMOVE = "削除"
    REPLACE = "置き換え"
    FROM_WEEK = "第 N 週以降"


@dataclass(frozen=True)
class CrewChange:
    mode: CrewMode
    members: tuple[Assignee, ...] = ()  # ADD・REMOVE は 1 人(REMOVE は名前だけ使う)。REPLACE・FROM_WEEK は一覧

@dataclass(frozen=True)
class BulkChanges:
    crew: CrewChange | None = None
    category: CategoryChange | None = None
    end: EndChange | None = None
    effort: EffortChange | None = None

    @property
    def any_change(self) -> bool:
        return any(c is not None for c in (self.crew, self.category, self.end, self.effort))


@dataclass
class BulkResult:
    tasks: dict[str, Task] = field(default_factory=dict)  # 変わったタスクだけ(id → 変更後)。描画順
    skips: Counter[str] = field(default_factory=Counter)  # 理由 → 項目の数
    review_needed: int = 0  # 換算率が変わり、完了予定の見直しが要るタスク
    manual_switched: int = 0  # 自動算出から手で指定に変わったタスク(工数あり)
    weeks_dropped: int = 0  # 置き換えで週ごとが解除されたタスク
    emptied: int = 0  # 担当の削除で担当なしになったタスク
    filled_weeks: int = 0  # 担当の削除で空になり、隣の週と同じにした週

    @property
    def changed(self) -> int:
        return len(self.tasks)

    @property
    def skipped(self) -> int:
        return sum(self.skips.values())

    def skip(self, reason: str) -> None:
        self.skips[reason] += 1


def _category(task: Task, change: CategoryChange, result: BulkResult) -> Task:
    if task.kind not in CATEGORY_KINDS:
        result.skip(SKIP_KIND)
        return task
    return replace(task, category_id=change.category_id)


def _effort(task: Task, change: EffortChange, result: BulkResult) -> Task:
    if task.kind is not TaskKind.NORMAL:
        result.skip(SKIP_KIND)
        return task
    if change.mode is EffortMode.SET:
        hours = round(change.hours, DECIMALS)
    else:
        if task.effort_hours <= 0:
            result.skip(SKIP_NO_EFFORT)
            return task
        hours = round(task.effort_hours + change.hours, DECIMALS)
    if hours < 0:
        result.skip(SKIP_NEGATIVE)
        return task
    return replace(task, effort_hours=hours)


def _end(task: Task, original: Task, change: EndChange, project: Project, holidays: dict[date, str], result: BulkResult) -> Task:
    if task.kind is not TaskKind.NORMAL:
        result.skip(SKIP_KIND)
        return task
    if change.mode is EndMode.DATE:
        assert change.day is not None
        new_end = datetime.combine(change.day, project.work_start) + timedelta(hours=project.daily_hours)
    else:
        base = own_end(original, project, holidays)  # 押し出しを含めない(手指定にすると押し出しは二重に掛かるため)
        if base is None:
            result.skip(SKIP_NO_END)
            return task
        try:
            new_end = base + timedelta(days=change.days)
        except OverflowError:
            result.skip(SKIP_RANGE)
            return task
    if not MIN_YEAR <= new_end.year <= MAX_YEAR:
        result.skip(SKIP_RANGE)
        return task
    if task.planned_start is not None and new_end < task.planned_start:
        result.skip(SKIP_BEFORE_START)
        return task
    if task.effort_hours > 0 and not task.planned_end_manual:
        result.manual_switched += 1
    return replace(task, planned_end=new_end, planned_end_manual=True)


def apply_bulk(project: Project, ids: Sequence[str], changes: BulkChanges, holidays: dict[date, str]) -> BulkResult:
    """ids(描画順)のタスクに changes を当てた結果を返す。project は変えない(ダイアログの見込みにも使う)。
    項目の順は 担当 → カテゴリ → 工数 → 完了予定。ずらしの基準は、元のタスクの完了予定。"""
    by_id = project.task_map()
    schedule = Schedule(project, holidays)
    result = BulkResult()
    for task_id in ids:
        original = by_id.get(task_id)
        if original is None:
            continue
        task = original
        if changes.crew is not None:
            task = _crew(task, changes.crew, project, holidays, schedule, result)
        if changes.category is not None:
            task = _category(task, changes.category, result)
        if changes.effort is not None:
            task = _effort(task, changes.effort, result)
        if changes.end is not None:
            task = _end(task, original, changes.end, project, holidays, result)
        if task != original:
            result.tasks[task_id] = task
    return result


def _task_lists(project: Project) -> list[list[Task]]:
    return [project.tasks, *(section.tasks for _, section in walk_sections(project.sections))]


def store(project: Project, result: BulkResult) -> None:
    """結果のタスクを、同じ id のタスクの位置に差し込む(並びは変えない)。"""
    for tasks in _task_lists(project):
        for index, task in enumerate(tasks):
            if task.id in result.tasks:
                tasks[index] = result.tasks[task.id]
```

```python
def _crew(
    task: Task, change: CrewChange, project: Project, holidays: dict[date, str], schedule: Schedule, result: BulkResult

        result.skip(SKIP_KIND)
        return task

def _crew_applied(
    task: Task, change: CrewChange, project: Project, holidays: dict[date, str], schedule: Schedule, result: BulkResult
) -> Task:
    weeks = task.weekly_crew
    if change.mode is CrewMode.ADD:
        who = change.members[0]

        def add(crew: Sequence[Assignee]) -> list[Assignee]:
            merged = [Assignee(a.name, who.allocation if a.name == who.name else a.allocation) for a in crew]
            return merged if any(a.name == who.name for a in crew) else [*merged, Assignee(who.name, who.allocation)]

        if weeks:
            added = [add(w) for w in weeks]
            return replace(task, weekly_crew=added, assignees=union_assignees(added))
        return replace(task, assignees=add(task.assignees))
    if change.mode is CrewMode.REMOVE:
        name = change.members[0].name

        def drop(crew: Sequence[Assignee]) -> list[Assignee]:
            return _copy([a for a in crew if a.name != name])

        if weeks:
            filled, empties = fill_empty_weeks([drop(w) for w in weeks])
            if not filled:  # 全週が空: 週ごとをやめて担当なしにする
                result.emptied += 1
                return replace(task, weekly_crew=[], assignees=[])
            result.filled_weeks += len(empties)
            return replace(task, weekly_crew=filled, assignees=union_assignees(filled))
        crew = drop(task.assignees)
        if task.assignees and not crew:
            result.emptied += 1
        return replace(task, assignees=crew)
    if change.mode is CrewMode.REPLACE:
        if weeks:
            result.weeks_dropped += 1
        return replace(task, weekly_crew=[], assignees=_copy(change.members))
    # FROM_WEEK: 第 N 週から後ろを丸ごと上書きする
    if not weeks:
        if not task.assignees:
            result.skip(SKIP_NO_CREW)
            return task
        start = effective_start(task, project, holidays, schedule)
        if start is None:
            result.skip(SKIP_NO_START)
            return task
        end = effective_end(task, project, holidays, schedule)
        count = week_count(start, end) if end is not None and end > start else 1
        weeks = [_copy(task.assignees) for _ in range(count)]
    head = [_copy(w) for w in weeks[: change.from_week - 1]]
    while len(head) < change.from_week - 1:
        head.append(_copy(head[-1]))  # 定義した週より後ろは、最後の週の担当が続いていた
    new_weeks = [*head, _copy(change.members)]
    return replace(task, weekly_crew=new_weeks, assignees=union_assignees(new_weeks))

class DeleteSummary:
    total: int
    summaries: int  # うちまとめ
    children: int  # うちまとめの子
    running: int  # うち実行中の記録(終了のない区間)があるもの


def delete_summary(project: Project, ids: Collection[str]) -> DeleteSummary:
    """削除の確認に出す件数。"""
    by_id = project.task_map()
    parents = parent_map(project)
    chosen = [by_id[i] for i in ids if i in by_id]
    return DeleteSummary(
        total=len(chosen),
        summaries=sum(1 for t in chosen if t.kind is TaskKind.SUMMARY),
        children=sum(1 for t in chosen if t.id in parents),
        running=sum(1 for t in chosen if any(a.end is None for a in t.actuals)),
    )


def delete_tasks(project: Project, ids: Collection[str]) -> int:
    """ids のタスクを取り除き、先行・まとめの子から外す(単独の削除と同じ規則)。消した件数を返す。"""
    removed = 0
    for task_id in ids:
        for tasks in _task_lists(project):
            index = next((i for i, t in enumerate(tasks) if t.id == task_id), None)
            if index is not None:
                del tasks[index]
                drop_task_links(project, task_id)
                removed += 1
                break
    return removed
```

```python
    def apply_bulk(self, ids: list[str], changes: BulkChanges) -> None:
        """一括編集を適用する。置き換えで週ごとが解除されるときだけ、先に件数を出して確認する。"""
        result = bulk_edit.apply_bulk(self.project, ids, changes, self.holidays)
        if result.weeks_dropped:

                lambda: self.commit_bulk(result),
                detail="置き換えると、週ごとの担当は 1 つの担当に戻ります",
                confirm_label="適用",
            )
            return

    def commit_bulk(self, result: bulk_edit.BulkResult) -> None:
        store(self.project, result)
        self.after_edit()  # 適用 1 回 = Undo 1 ステップ
        ui.notify(f"{result.changed} 件を一括編集しました")
        if result.skipped:
            ui.notify(f"スキップ {result.skipped} 項目: " + "・".join(f"{r} {n}" for r, n in result.skips.items()), type="warning")
        if result.review_needed:
            ui.notify(f"完了予定の見直しが要るタスクが {result.review_needed} 件あります", type="warning")
        if result.manual_switched:
            ui.notify(f"自動算出から手で指定に変わったタスク {result.manual_switched} 件(設定を変えても追従しません)", type="warning")
        if result.emptied:
            ui.notify(f"担当がいなくなったタスクが {result.emptied} 件あります", type="warning")
        if result.filled_weeks:
            ui.notify(f"担当のいなくなった週 {result.filled_weeks} 週を、隣の週の担当にしました", type="warning")
        self.warn_overallocation(*result.tasks.values(), limit=3)

    def confirm_bulk_delete(self, ids: list[str]) -> None:
        if not ids:
            return
        info = delete_summary(self.project, ids)
        message = f"{info.total} 件のタスクを削除します(うちまとめ {info.summaries} 件・子 {info.children} 件)"
        detail = f"実行中の記録があるタスクが {info.running} 件あります" if info.running else None
        open_confirm_dialog(message, lambda: self.bulk_delete(ids), detail=detail)

        delete_tasks(self.project, ids)
        self.gantt.clear_selection()
        self.after_edit()
```
