# イベントカレンダー Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** プロジェクトごとに期間・文字列・色を持つ「イベント」を登録し、ガントチャートの日付ヘッダーの下に文字の帯として、期間のセルを色で表示する。

**Architecture:** 純粋関数モジュール `events.py`(検証・段の割り当て・列との重なり・セルの色)と、`models.Event` を土台にする。ファイル形式は version 4(`events` キー)。描画は `gantt.py` に、ヘッダー下の帯の行と、`stripes` と同じ全体を覆う色の層を足す。登録は設定ダイアログの「イベント」の節。git のマージは `merge.py` に `event` の集合を足す。

**Tech Stack:** Python 3.13、NiceGUI、pytest(`uv run pytest`)。

**Spec:** `docs/superpowers/specs/2026-10-15-events-design.md`

## Global Constraints

- 言語は日本語(UI の文言・コメント・テスト名の説明)。コードの識別子は英語。
- `Event(start, end, text, color, id)`: `end` は終了日を含む。`start ≤ end`。文字列は 1〜30 文字(`MAX_EVENT_TEXT_LENGTH = 30`)で、制御文字・書式制御文字・行/段落区切り(`models.has_control_char`)を含まない。
- 色は CSS の色名(大文字小文字は区別せず、保存は小文字)。`#RRGGBB` は受け付けない。
- `FORMAT_VERSION = 4`。キーのない古いファイルは `events = []` で読む(version 3 以下では `events` キーを見ない)。不正な値は読込を拒否する。
- 重なる期間は段(レーン)を重ねる。セルの色は、リストの後ろのイベントが勝つ。保存時に開始日(次に終了日)の昇順に並べ替える。
- 日次・週次・月次のすべてのスケールで出す。列は `[start, end)`(終端を含まない)なので、イベントの終了日は翌日と比べる。
- ダークテーマでは同じ色を、より低い不透明度で塗る。
- 絞り込み・折りたたみの影響は受けない。プレビュー(読み取り専用)・画像保存にも出す。プレビューの表示項目に「イベント」(既定オン)を足す。
- 利用者の文字列は HTML に埋め込まない(`ui.label` で出す)。`ui.html` に入る内容は、定数・検証済みの色・数値だけにする。
- 対象外: ダッシュボード、担当者向けの書き出し、ドラッグでの帯の編集、時刻つきのイベント、件数の上限、`#RRGGBB`。
- 完了の確認は `uv run pytest -n auto` と `uv run ty check src`。コミットメッセージは日本語で、末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` を付ける。

## Review Focus

- 終了日が表示期間の外(前・後)のイベント: 帯もセルの色も出さず、エラーにならない(Task 1 `column_span`・Task 4)。
- 1 日だけのイベント(`start == end`)を週次・月次で出す: その日を含む 1 列だけが塗られ、帯の幅は 1 列分(Task 1・Task 4)。
- 同じ日に始まり終わる複数のイベント、前の終了日の翌日に始まるイベント: 段を無駄に増やさない(Task 1 `assign_lanes`)。
- 色名の大文字小文字・前後の空白(`Red `): 受け付けて小文字で保存する。`transparent`・`#fff`・空は拒否する(Task 1・Task 2・Task 6)。
- 旧い version 3 のファイルを開いて保存し直す: イベントなしのまま version 4 で保存され、開き直せる。version 5 は拒否される(Task 2)。
- 設定ダイアログで日付を省略形(`10/20`)で入れる・空にする・終了日が開始日より前: 省略形は整い、不正は理由つきで拒否して、何も適用しない(Task 6)。

```python
def normalize_color(name: str) -> str | None:
    """色名を小文字にして返す。前後の空白は除く。CSS の色名でなければ None。"""
    key = name.strip().lower()
    return key if key in CSS_COLORS else None


def color_hex(name: str) -> str:
    """色名の #rrggbb。検証済みの色名だけを渡す。"""
    return CSS_COLORS[name]


def validate_events(events: Sequence[Event]) -> None:
    """イベントの一覧を検証する。不正は ValueError(理由つき)。"""
    ids: set[str] = set()
    for e in events:
        if not e.id or e.id in ids:
            raise ValueError(f"イベントの id が正しくありません: {e.id!r}")
        ids.add(e.id)
        if e.start > e.end:
            raise ValueError("イベントの終了日は開始日以降にしてください")
        if not e.text.strip():
            raise ValueError("イベントの文字列を入力してください")
        if len(e.text) > MAX_EVENT_TEXT_LENGTH:
            raise ValueError(f"イベントの文字列は{MAX_EVENT_TEXT_LENGTH}文字以内で入力してください")
        if has_control_char(e.text):
            raise ValueError("イベントの文字列に改行・制御文字は使えません")
        if e.color not in CSS_COLORS:
            raise ValueError(f"イベントの色が正しくありません: {e.color!r}(red・orange・gray などの色名)")


def sort_events(events: Sequence[Event]) -> list[Event]:
    """開始日、終了日の昇順。同じものは元の並びを保つ(安定)。"""
    return sorted(events, key=lambda e: (e.start, e.end))


def assign_lanes(events: Sequence[Event]) -> list[int]:
    """イベントごとの段(0 から)。開始の早い順に、空いた最小の段へ詰める。前の終了日の翌日に始まるなら同じ段。入力と同じ順で返す。"""
    order = sorted(range(len(events)), key=lambda i: (events[i].start, events[i].end, i))
    lane_ends: list = []  # 各段の最後のイベントの終了日
    lanes = [0] * len(events)
    for i in order:
        for lane, last in enumerate(lane_ends):
            if last < events[i].start:
                lane_ends[lane] = events[i].end
                lanes[i] = lane
                break
        else:
            lanes[i] = len(lane_ends)
            lane_ends.append(events[i].end)
    return lanes


def count_lanes(lanes: Sequence[int]) -> int:
    return max(lanes, default=-1) + 1


def column_span(event: Event, columns: Sequence[Column]) -> tuple[int, int] | None:
    """期間に 1 日でも重なる列の、先頭の添字と列数。重ならなければ None。列は [start, end)。"""
    touched = [i for i, c in enumerate(columns) if c.start <= event.end and c.end > event.start]
    if not touched:
        return None
    return touched[0], len(touched)


def cell_colors(events: Sequence[Event], columns: Sequence[Column]) -> list[str | None]:
    """列ごとの色名。重なる列は、リストの後ろのイベントの色になる。"""
    colors: list[str | None] = [None] * len(columns)
    for e in events:
        span = column_span(e, columns)
        if span is not None:
            first, count = span
            for i in range(first, first + count):
                colors[i] = e.color
    return colors
```

```python
def _events(value: Any) -> list[Event]:
    """イベント(version 4)。キーがない・null は空。日付・文字列・色・id の不正は ValueError。"""
    if value is None:
        return []
    if not isinstance(value, list):
        raise ValueError("イベントがリストではありません")
    events: list[Event] = []
    for raw in value:
        if not isinstance(raw, dict):
            raise ValueError("イベントの形式が正しくありません")
        dates = []
        for key, label in (("start", "開始日"), ("end", "終了日")):
            text = raw.get(key)
            if not isinstance(text, str):
                raise ValueError(f"イベントの{label}が文字列ではありません: {text!r}")
            dates.append(date.fromisoformat(text))  # 形式の不正は ValueError
        text = raw.get("text")
        if not isinstance(text, str):
            raise ValueError(f"イベントの文字列が文字列ではありません: {text!r}")
        color = raw.get("color", "gray")
        normalized = normalize_color(color) if isinstance(color, str) else None
        if normalized is None:
            raise ValueError(f"イベントの色が正しくありません: {color!r}")
        events.append(Event(dates[0], dates[1], text.strip(), normalized, _entity_id(raw.get("id"), "イベント")))
    validate_events(events)
    return events
```

```python
_ISO_DATE = re.compile(r"[0-9]{4}-[0-9]{2}-[0-9]{2}")


def _iso_date(text: Any, label: str) -> date:
    if not isinstance(text, str) or _ISO_DATE.fullmatch(text) is None:
```

```python
@dataclass
class EventRow:
    """設定ダイアログのイベントの 1 行。originalは、開いた時点のイベントの id(新しい行はNone)。"""

    original: str | None
    start: str  # YYYY-MM-DD か、省略形(10/20・1020・20261020)
    end: str
    text: str
    color: str  # 色名


def build_event_list(rows: list[EventRow], taken: Collection[str], today: date) -> list[Event]:
    """入力の行を検証して、並べ替えたイベントの一覧にする。完全に空の新しい行は無視する。新しい行には、既存の id と重ならない id を振る。"""
    used = set(taken)
    built: list[Event] = []
    for row in rows:
        if row.original is None and not any(t.strip() for t in (row.start, row.end, row.text)):
            continue
        days = []
        for text, label in ((row.start, "開始日"), (row.end, "終了日")):
            parsed = parse_date_input(text, today, roll_forward=False)
            if parsed is None:
                raise ValueError(f"イベントの{label}を日付で入力してください(例: 2026-10-20、10/20)")
            days.append(date.fromisoformat(parsed))
        color = normalize_color(row.color)
        if color is None:
            raise ValueError(f"イベントの色が正しくありません: {row.color.strip()!r}(red・orange・gray などの色名)")
        event_id = row.original or new_id(used)
        used.add(event_id)
        built.append(Event(days[0], days[1], row.text.strip(), color, event_id))
    validate_events(built)
    return sort_events(built)
```
