# 実績の入力 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** タスクの実績(開始〜終了)を編集ダイアログで入力・保存し、状態の提案、実績に基づく超過判定、ガントチャートの実績の棒(予定の棒は半透明)を実現する。

**Architecture:** 実績は `Task.actuals: list[Actual]` で持つ(今回の画面は 0〜1 件)。検証は `forms.py`、保存は `storage.py`、判定は `timeline.py`、描画は `gantt.py`。ダイアログの実績の入力は `task_dialog.py` の `ActualFields` に切り出す。

**Tech Stack:** Python 3.13、NiceGUI、pytest(`nicegui.testing.User`)、`ty`。

**Spec:** `docs/superpowers/specs/2026-10-04-actuals-design.md`

## Global Constraints

- テストは `test/` 配下。実行は `uv run pytest -q`、型チェックは `uvx ty check src`。
- 日時はタイムゾーンなし。年は `MIN_YEAR`〜`MAX_YEAR`(2000〜2100)。
- 読込時の不正は `ValueError`(`views.open_project` が「開けませんでした」と通知する)。
- 日付と時刻の文字列形式は `%Y-%m-%d` と `%H:%M`、合成は `YYYY-MM-DDTHH:MM`。
- 画面の文言は日本語。コメントは既存のコードに合わせて日本語で簡潔に。
- 色は `is_hex_color` を通ったものだけを CSS に入れる(既存の `task_row` と同じ扱い)。
- コミットメッセージの末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` を付ける。

## Review Focus

- 実績が 2 件以上のファイルを開いて保存しても、実績が消えない・書き換わらない(`build_task` が既存の実績を保つ)。
- 実績の日付だけ、時刻だけを入れて保存しようとすると、エラーが出て保存されない。
- 開始なしで終了だけを入れると、エラーになる。
- 進行中の実績の開始が現在時刻より未来でも、棒が出て、描画が壊れない(最小幅)。
- 実績の終了があって状態が「終了」でないタスク、実績の終了がなく状態が「終了」のタスクで、超過判定が設計書どおり(後者は超過でない)。
- 古いファイル(`actuals` キーなし)と、`actuals` が `null` のファイルが、実績なしで開ける。
- 行のコピーで実績が複製されない。バーの横移動で実績が動かない。

```python
def _actual_moment(value: Any, label: str) -> datetime:
    if not isinstance(value, str):
        raise ValueError(f"実績の{label}が文字列ではありません")
    moment = _datetime(value)
    if moment is None or moment.tzinfo is not None:
        raise ValueError(f"実績の{label}の形式が正しくありません: {value!r}")
    return moment


def _actuals(value: Any) -> list[Actual]:
    """実績を読む。キーがない・nullは実績なし。不正はValueError(開けませんでした)。"""
    if value is None:
        return []
    if not isinstance(value, list):
        raise ValueError("実績がリストではありません")
    actuals: list[Actual] = []
    for raw in value:
        if not isinstance(raw, dict) or "start" not in raw:
            raise ValueError("実績に開始がありません")
        start = _actual_moment(raw["start"], "開始")
        end = None if raw.get("end") is None else _actual_moment(raw["end"], "終了")
        if end is not None and end < start:
            raise ValueError("実績の終了が開始より前です")
        actuals.append(Actual(start, end))
    return actuals
```

`_datetime("")` は `None` を返すので、空文字は `moment is None` で拒否される。

```python
def compose_actual(day: str, clock: str) -> str:
    """実績の日付と時刻から文字列を作る。両方空は空、片方だけはエラー(実績は時刻を補わない)。"""
    if not day.strip() and not clock.strip():
        return ""
    if not day.strip() or not clock.strip():
        raise ValueError("日付と時刻を両方入れてください")
    return compose_datetime(day, clock)


def suggest_status(has_start: bool, has_end: bool) -> Status | None:
    """実績の入力から、提案する状態。開始なし(終了だけを含む)は提案しない。一時停止は提案しない。"""
    if not has_start:
        return None
    return Status.DONE if has_end else Status.RUNNING


def build_actuals(start_text: str, end_text: str) -> list[Actual]:
    """実績の入力(compose_actual の結果)を検証して、0件か1件の区間にする。"""
    try:
        start_at, end_at = parse_datetime(start_text), parse_datetime(end_text)
    except ValueError:
        raise ValueError("実績の日時の形式が正しくありません") from None
    if start_at is None:
        if end_at is not None:
            raise ValueError("実績の開始を入れてください")
        return []
    for moment in (start_at, end_at):
        if moment and not MIN_YEAR <= moment.year <= MAX_YEAR:
            raise ValueError(f"年は{MIN_YEAR}〜{MAX_YEAR}の範囲で入力してください")
    if end_at is not None and end_at < start_at:
        raise ValueError("実績の終了は開始以降の日時にしてください")
    return [Actual(start_at, end_at)]
```

`build_task` の引数 `allocation_percent: float | None,` の次に `actual_start: str = "", actual_end: str = "",` を足す。`return replace(` の直前に `actuals = base.actuals if len(base.actuals) > 1 else build_actuals(actual_start, actual_end)` を置き、`replace(...)` に `actuals=actuals,` を足す(`allocation=allocation,` の次)。`build_actuals` の検証は、ほかの検証より後(`assignee` の検証の後)で呼ばれるようにする位置に置くこと(既存のエラーの優先順位を変えない)。

```python
def actual_end(task: Task) -> datetime | None:
    """実績の終了。実績がない、または終了のない区間があれば None。複数あるときは最後の区間の終了。"""
    if not task.actuals or any(a.end is None for a in task.actuals):
        return None
    return task.actuals[-1].end


def is_overdue(
    task: Task, project: Project, holidays: dict[date, str], now: datetime
) -> bool:
    """締切か完了予定を過ぎている。実績の終了があれば、その時刻で判定する(遅れて終わったものも超過)。
    実績の終了がなければ、状態が「終了」でない間だけ、現在時刻と比べる。"""
    finished = actual_end(task)
    moment = finished
    if moment is None:
        if task.status is Status.DONE:
            return False
        moment = now
    if task.deadline is not None and moment > task.deadline:
        return True
    end = effective_end(task, project, holidays)
    return end is not None and moment > end
```

```python
class ActualFields:
    """実績の開始・終了。日付と時刻を両方入れる(補う時刻はない)。2件以上の実績は編集できない。"""

    def __init__(self, task: Task) -> None:
        self.read_only = len(task.actuals) > 1
        ui.label("実績").classes("text-caption text-grey")
        if self.read_only:
            ui.label("複数の区間があるため、このバージョンでは編集できません").classes(
                "text-caption"
            ).mark("task-actuals-readonly")
            return
        actual = task.actuals[0] if task.actuals else None
        with ui.row().classes("w-full no-wrap gap-4"):
            self.start_day, self.start_time = self._column("開始", "start", actual.start if actual else None)
            self.end_day, self.end_time = self._column(
                "終了", "end", actual.end if actual else None
            )

    def _column(
        self, label: str, key: str, moment: datetime | None
    ) -> tuple[ui.input, ui.input]:
        with ui.column().classes("flex-1 gap-0"):
            day = ui.input(
                f"{label}の日付", value=moment.strftime("%Y-%m-%d") if moment else ""
            )
            day.classes("w-full").mark(f"task-actual-{key}-date")
            add_picker(day, ui.date, "event", f"actual-{key}-date", "%Y-%m-%d")
            clock = ui.input(
                f"{label}の時刻", value=moment.strftime("%H:%M") if moment else ""
            )
            clock.classes("w-full").mark(f"task-actual-{key}-time")
            add_picker(clock, ui.time, "access_time", f"actual-{key}-time", "%H:%M")
        return day, clock

    def inputs(self) -> list[ui.input]:
        return [] if self.read_only else [self.start_day, self.start_time, self.end_day, self.end_time]

    def start_text(self) -> str:
        return "" if self.read_only else compose_actual(self.start_day.value or "", self.start_time.value or "")

    def end_text(self) -> str:
        return "" if self.read_only else compose_actual(self.end_day.value or "", self.end_time.value or "")

    def filled(self) -> tuple[bool, bool]:
        """開始・終了の日付と時刻がそろっているか(状態の提案に使う)。"""
        if self.read_only:
            return False, False
        return (
            bool((self.start_day.value or "").strip() and (self.start_time.value or "").strip()),
            bool((self.end_day.value or "").strip() and (self.end_time.value or "").strip()),
        )

    def state(self) -> tuple[object, ...]:
        return tuple(widget.value or "" for widget in self.inputs())
```

```python
        def on_actual_change(_event: object = None) -> None:

            suggested = suggest_status(*actual_fields.filled())
            if suggested is None or suggested == status.value:

            hint.set_text("実績に合わせて状態を変えました")
            hint.set_visibility(True)

            widget.on_value_change(on_actual_change)
```
