# ガントチャート基本表示 設計書

## 目的

メイン画面のチャート領域に、セクションとタスクのバーを表示する。日・週・月のスケールを切り替え、土日祝を背景色で区別し、タスクを追加・編集できる。

## 範囲

**含む**: 基本表示、スケール切替、土日祝の背景、タスクとセクションの追加・編集、祝日データの取得とキャッシュ。

**含まない**（後続のサブプロジェクト）:
- 工数からの終了日時の自動算出、予定超過の赤表示
- ドラッグ&ドロップ（移動・コピー）、検索、担当者の絞り込み
- タスク同士の矢印連結、添付ファイル
- 人的リソースの割り当て比率（最大100%）

## 描画方式

NiceGUI 要素と CSS グリッドによる自前描画。バーは開始日時と期間から位置と幅を計算して配置する。

## 構成

| モジュール | 役割 | 依存 |
|---|---|---|
| `calendar.py` | 祝日の取得・キャッシュ(`holidays.json`)と日付種別の判定 | httpx |
| `timeline.py` | スケールごとの列生成、日時から位置・幅への変換。NiceGUI に依存しない純粋関数 | models |
| `gantt.py` | 日付目盛り、セクション行、タスクのバー、スケール切替トグルの描画 | timeline, calendar |
| `forms.py` | タスク・セクションの追加・編集ダイアログ | models |

`views.py` の `chart()` を `gantt.py` の呼び出しに置き換える。

## データの流れ

1. `MainView` が現在の `Project` を保持する。
2. `gantt` は `Project` とスケールを受け取り、`timeline` で列と位置を計算して描画する。
3. ダイアログで `Project` を更新したら、チャート領域のみ再描画する(`refreshable`)。
4. 祝日は起動時に `holidays.json` を読む。ファイルがない初回のみ自動で取得し、以降は更新ボタンを押したときだけ再取得する。

## スケールと表示範囲

| スケール | 1列 | 最小表示幅 |
|---|---|---|
| 日次 | 1日 | 42日 |
| 週次 | 1週間(月曜始まり) | 26週 |
| 月次 | 1か月 | 12か月 |

- 見出しは、年の帯、月の帯(月次スケールを除く)、列の見出しの順に上から並べる。年・月の帯は、その年・月に属する列をまたいで結合した1つのセルにし、中に「2026年」「10月」と表示する。
- 列の見出しは、日次は日付(「5」)と下段の曜日(「（月）」)、週次は週の開始日(「5~」)、月次は月(「10月」)とする。週は開始日が属する月に数える。
- 格子線は全スケールで、列の境界の縦線と各行の下の横線を引く。縦線は年・月の帯の下から始める(結合セルの中には引かない)。
- 表示範囲は、基準日からタスクの最終終了日までとする。最小表示幅に満たなければ延長する。
- 基準日より前に開始するタスクがある場合は、最も早い開始日まで範囲を広げる。
- バーは開始・終了が両方設定されたタスクのみ描画する。未設定のタスクは、名前の行だけ表示する。
- バーの位置・幅は、スケールによらず日時の連続値から計算する。

## 土日祝の背景

日次スケールのみ、列の背景色を付ける。週次・月次は付けない。

| 種別 | 色 |
|---|---|
| 土曜 | 薄い青 |
| 日曜 | 薄いピンク |
| 祝日 | 薄い緑(土日と重なる場合は祝日を優先) |

ライト・ダークの両テーマで読めるよう、半透明色で指定する。

## 祝日データ

- 取得元は内閣府の祝日CSV。`httpx` で取得し、`~/.projectapp/holidays.json` に保存する。
- 起動時に `holidays.json` があれば読み、取得はしない。
- `holidays.json` がない初回のみ、起動時に一度だけ自動で取得する。取得が終わるまでは祝日なしで表示し、完了したら再描画する。
- 初回の取得に失敗した場合は、通知を出して祝日なしで表示を続ける。ファイルは作らないので、次回の起動で再び初回扱いとして取得を試みる。
- 以降の更新は「祝日を更新」ボタン(ヘッダーのプロジェクト名の右隣)で行う。失敗したときは通知を出し、既存のキャッシュを保つ。

## セクションに属さないタスク

- `Project.tasks` に、セクションに属さないタスクを持てる。チャートでは、見出しなしで、セクションより上に並べる。
- セクションなしのタスクの末尾に、細い追加行を常に1行出し、名前の列の右端に「タスク追加」ボタンを置く。ボタンはこの一覧に追加する。タスクが1件もないときは、見出しの直下に出る。ツールバーに「タスク追加」ボタンは置かない。
- セクションに入れたい場合は、セクション行の「+」を使う。
- 保存・読込は `tasks` も対象にする。`tasks` のない既存ファイルは空として読む。

## 追加・編集

- 「セクション追加」ボタンでセクション名を入力して追加する。
- 各セクションの「タスク追加」ボタンと、バーまたは行のクリックで、タスクのダイアログを開く。
- ダイアログの項目: 名前、開始日時、終了日時、工数(時間)、優先度、状態、色、担当者。
- 入力検証: 名前は必須。終了が開始より前の場合はエラーを表示して保存しない。

## エラー処理

- 祝日の取得失敗(初回・更新とも)は、通知のみで画面の表示は続ける。
- 日付の入力不正は、ダイアログ内にメッセージを出して保存しない。

## テスト

- `timeline`: スケールごとの列数、バーの位置と幅、表示範囲の拡張を、純粋関数のユニットテストで確認する。
- `calendar`: CSV の解析、キャッシュの読み書き、初回のみ自動取得すること、取得失敗時のフォールバックを、`httpx` をモックして確認する。
- `gantt` / `forms`: NiceGUI の `User` テストで、セクションとタスクの表示、スケール切替、追加・編集、入力検証を確認する。
