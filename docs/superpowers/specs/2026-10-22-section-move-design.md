# セクションの並べ替え(ドラッグ)の設計

> **状態**: 設計済み(2026-10-22)— 番号のない要望 — `feature/section-move`。現在の仕様は実装後に [`CLAUDE.md`](../../../CLAUDE.md) へ反映する。

## 目的

ガントチャートのセクションは、コピー・名前の変更・削除はできるが、並べ替えられない(`CLAUDE.md` は「移動はできない」としている)。
セクションの見出しをドラッグして、同じ親の兄弟のあいだで並べ替えられるようにする。成功の目安は次のとおり。

- 見出しの名前の欄をつかんで、同じ親の兄弟の見出しに落とすと、その位置に入る。
- 中のタスク・サブセクションは一緒に動く。折りたたみの状態は、セクションに付いたまま動く。
- 元に戻す(`Ctrl/Cmd+Z`)の 1 ステップで戻せる。
- ファイル形式(`version`)は変えない。

## 決めたこと(2026-10-22 に確認済み)

| 項目 | 決定 |
| --- | --- |
| 操作 | ドラッグ&ドロップだけ(右クリックの`上へ`・`下へ`は足さない) |
| 動かせる範囲 | 同じ親の中だけ(root のセクション同士、同じセクション内のサブセクション同士)。別の親・階層へは移せない |
| 落とす先 | 同じ親の兄弟の見出し。落とすと、動かしたセクションがその見出しの位置に入る(上へ動かせばその手前、下へ動かせばその後ろ) |
| 強調 | 落とせる見出しの全体を、枠線(`drop-into`)で囲む。上下の線は使わない(展開中は見出しの下に中身が続くので、線だと「中に入る」ように見えるため) |
| つかむ場所 | 見出しの名前の欄(タスクの行と同じ。専用のアイコンは足さない) |
| 無効にする場面 | 絞り込み中、プレビュー(読み取り専用) |

## 並べ替え(`arrange.py`)

- `move_section(project, path, to_index) -> bool`: `path` のセクションを、同じ親の一覧(`_sections_list`)の `to_index` の位置へ移す。
  - 一覧から取り除いて `to_index` に挿入するだけで、`id`・名前・中身は変えない。
  - 範囲外、または `to_index` が今の位置と同じなら、何もせず `False`(履歴を積まない)。移したら `True`。
- `reorder_collapsed(collapsed, parent, src, dst) -> set[SectionPath]`: 兄弟の `src` を `dst` へ移したときの、折りたたみのパスの付け替え。
  - `parent` の下の `src` と子孫のパスは `dst` へ。`src` と `dst` のあいだの兄弟とその子孫は、1 つずつずらす。範囲の外は変えない。
  - `remap_collapsed`(挿入・削除)の仲間として、同じ場所に置く。
- ドロップのメッセージの検証: `parse_section_move(args) -> tuple[SectionPath, SectionPath] | None`。`{src, dst}` の両方がセクションのパス(`parse_section` と同じ書式)で、`src[:-1] == dst[:-1]`(同じ親)のときだけ通す。

## ブラウザ側(`gantt_drag.py`)

- 見出しの名前の欄に、`draggable=true`・`data-section-handle`・`data-si=<キー>`・`data-parent=<親のキー>`(root の親は`top`)を付ける。
- 専用の drag 種別 `application/x-gantt-section` を使い、タスクの行のドラッグ(`application/x-gantt-row`)と混ざらないようにする。
  - タスクの行のドラッグ中は、見出しの`drop-into`(タスクをセクションへ入れる)の動きを今のまま保つ。
  - セクションのドラッグ中は、同じ `data-parent` の見出しの上でだけ `preventDefault` して`drop-into` を出す。それ以外(親が違う見出し・タスクの行)の上では何もしない(禁止カーソルのまま)。
- 落とすと `emitEvent("chart_move_section", {src, dst})`(パスのキー)を送る。`dragend` で強調を消す。
- 名前の欄の右端での幅の調整中は、ドラッグを始めない(今の `dragstart` の除外をそのまま使う)。
- 見出しのクリック(折りたたみ)・ダブルクリック(名前だけのタスクの追加)・右クリックのメニューは変えない。

## 受け取りと反映(`gantt.py`・`views.py`)

- `GanttChart.handle_move_section(args)`: 絞り込み中・読み取り専用・`parse_section_move` が通らない・`valid_section` でないときは無視する。通れば `actions.move_section(src, dst)` を呼ぶ。
- `GanttChart.reorder_collapsed(parent, src, dst)`: `arrange.reorder_collapsed` で `collapsed` を付け替える(`remap_collapsed` と同じ作り。再描画は呼び出し側)。
- `views.py` の `move_section(src, dst)`: 同じ親でなければ何もしない。`arrange.move_section` が `True` のときだけ、`gantt.reorder_collapsed` で折りたたみを付け替え、`after_edit()` で再描画する。履歴は`after_edit`が差分で積むので、`False`(何も変わらない)なら積まれない。
- 再描画は、スクロール位置を動かさない(`set_project` の既存の挙動)。

## 仕様書の更新

- `CLAUDE.md` の「サブセクションは…移動はできない」を、「同じ親の中でのドラッグでの並べ替えはできる(別の親・階層へは移せない)」に直す。
- 右クリックのメニューの項目(`コピー`・`名前の変更`・`削除`)は変えず、並べ替えはドラッグであることを、セクションの節に 1 文で足す。

## 含まないもの

階層をまたぐ移動、右クリックの`上へ`・`下へ`、ドラッグ中の自動スクロール、複数セクションの同時移動、セクションを`Alt` で複製しながら動かす操作。

## テスト

- `arrange`(`test_arrange.py`):
  - 上へ・下へ・先頭・末尾・サブセクション(2・3 階層)。中のタスク・サブセクションと `id` が変わらない。
  - 同じ位置・範囲外は `False` で何も変えない。
  - `reorder_collapsed`: 動かしたセクションと子孫の折りたたみが付いて動く。間の兄弟がずれる。範囲の外・別の親は変わらない。
  - `parse_section_move`: 同じ親は通る。親が違う・不正な値・パスでない値は `None`。
- ガントチャート(`test_gantt.py`):
  - 見出しの名前の欄に `draggable`・`data-parent` が付く。読み取り専用では付かない。
  - 絞り込み中・読み取り専用では `handle_move_section` が何もしない。親が違うと何もしない。
  - 動かすと、表示の順と折りたたみの状態が付け替わる。
- 履歴(`test_history.py` など): 1 回の移動が元に戻す 1 ステップで、やり直しもできる。何もしなかった移動は履歴を積まない。
- 実機(ネイティブ): 見出しのドラッグ、強調、親が違う見出しへ落とせないこと、折りたたみの維持、元に戻す、ダークテーマの枠線、右端の幅調整・クリック・ダブルクリックの動作が変わらないこと。
