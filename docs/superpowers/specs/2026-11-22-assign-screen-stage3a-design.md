# 要望 168 段階 3a: アサイン専用画面の割り当て率のスライダー(設計)

## 目的

アサイン専用画面で、メンバーの割り当て率(`Assignee.allocation`。既定 100%)を、週・日のセルごとにスライダーで調整し、完了予定の変化を確定する前に見られるようにする。段階 3 は、このスライダー(3a)と、範囲を選んでの集中増員(3b)に分けた(2026-11-22)。3b・視点(段階 4)・負荷のヒストグラム(段階 5)は含めない。

## 決定(利用者の回答)

- 段階 3 は 3a(スライダー)→ 3b(集中増員)の順に、別の設計・PR で進める
- スライダーは、セルの中のアイコンをクリックして出す小さなポップアップに置く(セルの幅に左右されない)
- 効く範囲は、クリックしたセル(週・日)だけ。ポップアップに`このメンバーの全週に適用`を付ける
- ドラッグでの割り当ては 100% のまま
- ファイル形式は変えない(`version`は 24 のまま)。試算・確定・キャンセルは段階 1・2 のとおり

## 担当の操作(`daily_crew.py`に追加。NiceGUI に依存しない)

- `set_allocation(task, name, value, week, day=None, *, weeks=1) -> Task | None`
  - `value`は割り当て率(0.01〜1.0。`MIN_ALLOCATION`〜`MAX_ALLOCATION`)。範囲外・`nan` は`None`
  - 週ごとでないタスクは、`add_member`と同じく、現在の担当を`weeks`週ぶんに写して週ごとにしてから、その週だけを変える。定義済みの週より先は、直前の担当で埋めてから変える
  - 日ごとの週で`day`(0〜6)を指定したときは、その日だけを変える。`day`がないときは 7 日すべて。日ごとでない週で`day`を指定すると`None`
  - 日ごとの週を変えたら、その週の担当(`weekly_crew[week]`)は`union_assignees`で作り直す(同じ人は大きいほうの率)。`assignees`は`union_assignees(weekly)`
  - `None`(何も変えない): そのセルにメンバーがいない・値が今と同じ・`week`が 0 未満か`MAX_WEEKS`以上・通常でないタスク・担当者のいない週ごとでないタスク
- `set_allocation_all(task, name, value, *, weeks=1) -> Task | None`
  - そのメンバーがいるすべての週(日ごとの週はすべての日)の率を`value`にする。1 つも変わらなければ`None`
  - 週ごとでないタスクは、同じく週ごとにしてから変える
- `add_member`(100% で足す)・`remove_member`は変えない

## 画面(`assign_screen.py`の拡張)

- チップのアイコンをクリックすると、小さなポップアップ(`ui.menu`か`ui.card`。refreshable の中でダイアログを作らない学びに従い、画面の構築時に 1 つだけ作って使い回す)を開く。中身:
  - 見出し: メンバー名と、対象のセル(`第 N 週`。日ごとの週は`第 N 週 M 日目`)
  - スライダー(`ui.slider`。1〜100、5% 刻み)と数値欄(%。`ui.number`。1〜100)。どちらを変えても、もう一方に反映する
  - ボタン`このメンバーの全週に適用`
  - ボタン`閉じる`
- 値の確定の仕方: スライダーを離したとき(`update:model-value`ではなく`change`)と数値欄の確定で`set_allocation`を呼び、試算を更新してチャートを描き直す。ドラッグ中は描き直さない(重いため)
- アイコンの表示: 割り当て率が 100% でないときは、角に小さな数字(`80`)を重ねる。ツールチップは`田中 80%`。100% は名前だけ
- クリックと`×`・ドラッグの区別: `×`は今までどおりホバーで出し、押すと外す(ポップアップは開かない)。アイコンのクリックだけがポップアップを開く
- 完了予定: 割り当て率を下げると、棒の日程・完了予定・警告が試算で再計算される(既存の`trial_project`の経路)
- 確定・キャンセル・Esc: 段階 1・2 のとおり。変更の有無は`is_dirty`(率の違いも`Task`の比較に入る)

## 確かめること(実装の最初)

- `ui.slider`の`change`イベントで、離したときの値だけが取れるか(NiceGUI 4.0.0)。取れなければ、`update:model-value`をデバウンスする
- ポップアップをアサイン画面の全画面ダイアログの中で開いたとき、位置・重なり・Esc の扱いが破綻しないか(Esc はポップアップだけを閉じ、画面は閉じない)
- 倍率(`zoom`)中のスライダー・メニューの位置(要望 140 の学び)

足りないときは、この設計書を直して利用者に確認する。

## テスト

- 純粋関数: 範囲外・`nan`・同じ値・いないメンバー・日ごとの週で日の指定あり/なし・日ごとでない週で`day`指定・週ごとでないタスク・定義済みの週より先・52 週・通常でないタスク・`union_assignees`の反映・全週に適用(日ごとの週を含む)
- 画面: ポップアップの開閉・スライダーと数値欄の連動・バッジの表示(100% は出さない)・`×`でポップアップが開かない・確定で書き戻して元に戻す 1 ステップ・キャンセルで反映なし・率を下げると完了予定が後ろへずれる
