# ガントチャートの下部パネルと縦の分割の設計(要望 111・95)

> **状態**: 設計(2026-11-01 に会話で承認済み。分割の比率の指示を反映済み。設計書の確認待ち)。要望 111(縦の分割)と要望 95(下部の情報)を同時に実装する。architectural。

## 目的

メイン画面で、ガントチャートを広く見ながら、選んだタスクの詳細と、プロジェクトの状況を、画面を移らずに確かめられるようにする。ガントチャートを表示する縦幅は、利用者が変えられる。

## 利用者の要望(原文の要点)

- メインパネルを`ui.splitter`で縦に分け、ガントチャートの縦幅を拡大・縮小できるようにする(要望 111)。
- 下部のパネルは、状態に応じた見せ方にする(要望 95)。`Cmd/Ctrl`クリックで選んだタスクの**詳細**を出す。何も選んでいないときは、**表示期間の集計**を出し、**今日の予定**と**凡例**はタブで入れ替える。

## 決めたこと

| 項目 | 決定 |
|---|---|
| 分割 | `ui.splitter(horizontal=True)`。上=ガントチャート、下=情報パネル。全体の高さは今と同じ`calc(100vh - 170px)`。上の範囲は 30〜100%(100%で下を畳む) |
| 初回の比率 | 初回(保存した比率がないとき)は、ガントチャート 100%(下は畳む) |
| 開くときの比率 | タスクを選んだときに下が畳まれていれば、**ガントチャート 70%・下部パネル 30%**に開く(開いているときは動かさない。選択を解除しても畳まない)。この 70% は設定値(下記)で、既定値 |
| 設定値 | `開くときの比率`は、**全体の設定**(ヘッダーの設定アイコンから開くダイアログ。全プロジェクト共通)で、**スライダー**で変えられる(上のガントチャートの割合を 50〜90%、5% 刻み。既定 70%)。`~/.projectapp/config.json`の`bottom_open_ratio`に保存。不正な値は既定に戻す |
| 記憶と復元 | 分割の位置(ガントチャートの割合。畳んだ状態は 100%)を、**アプリを閉じるときに**`config.json`の`main_split`へ保存し、**起動時に**読み出して復元する(取りこぼさないよう、境界のドラッグを離したときにも保存する)。保存した値がなければ 100% |
| 連動 | 選択に連動する。ホバーには連動しない |
| 複数選択 | 最後に選んだ行(`BulkSelection.anchor`)の詳細を出し、「ほか n 件を選択中」を添える |
| 表示期間 | ツールバーの期間欄に従う。自動のときは、すべてのタスク。絞り込みにも従う |
| タブの記憶 | 保存しない。開くたびに`今日の予定` |
| プレビュー・ダッシュボード | パネルも分割も出さない。プレビューは今と同じく全体がチャート。ダッシュボードの表示中は、ガントチャートごと隠す(`set_visible`) |

## 画面の状態

| 状態 | 下部パネル |
|---|---|
| タスクを選んでいる | **詳細**だけ(全幅)。下が畳まれていれば、`開くときの比率`で開く |
| 何も選んでいない | 左に**集計**、右に**タブ**(`今日の予定` / `凡例`) |

詳細を出しているあいだも、選びなおす・解除する(`Esc`・`解除`)と、すぐ集計に戻る。

## 内容

- **詳細**(1 件): 名前、種別、状態、担当(割り当て率)、開始予定〜完了予定(手指定か算出か)、締切、工数、進捗度、実績の区間、リンク、先行。予定超過・期限超過・警告のときは理由の 1 行(名前の欄のホバーと同じ文言)。まとめは子の件数と範囲、プロジェクト参照は参照先の名前と遅れの件数、チェックポイントは締切と状態。
- **集計**: 見えているタスク(まとめ・チェックポイント・プロジェクト参照は数えない)について、状態別の件数、工数の合計(工数なしは数えず、`工数未設定 n 件`)、進捗率(工数で重みづけ)、遅れの件数(予定超過と期限超過)、警告の件数。ダッシュボードの`進捗と遅れ`と同じ判定を使う。
- **今日の予定**: 今日が日程(開始予定〜完了予定)にかかる、未終了の通常タスク。名前・担当・進捗度・完了予定を一覧にする。日程のないタスクは出さない。
- **凡例**: 棒の色(状態 4 つ)、名前欄の背景(優先度)、赤い行(遅れ)、黄色い行(警告)、縞(割り当て超過)、◆(締切とチェックポイント)、今日の線。色は画面と同じ定数から作る。

## 構成

| 部品 | 役割 |
|---|---|
| `bottom_info.py`(新) | NiceGUI に依存しない純粋関数。`task_detail`・`period_summary`・`today_plan`・`legend_entries`。判定は`timeline`・`pace`・`summary`・`dashboard`の既存関数を使い、新しい判定は作らない |
| `bottom_panel.py`(新) | 下部パネルの描画。選択の有無で詳細と集計を切り替え、タブを持つ |
| `gantt.py` | 枠を`ui.splitter`に入れる。選択・絞り込み・期間・描き直しのたびにパネルを更新する。プレビューではパネルを作らない |
| `config.py` | `main_split`・`bottom_open_ratio`の読み書き(`parse_main_split`・`parse_open_ratio`・`load_*`・`save_*`) |
| ヘッダーの設定アイコン(新) | ヘッダー右側の**テーマのメニューの左隣**に、設定のアイコンボタン(`settings`。マウスオーバーは`全体の設定`)を置く。押すと`全体の設定`のダイアログを開く。右側の並びは、…・格納フォルダ・**設定**・テーマ |
| `全体の設定`のダイアログ(新) | 今回の項目は`下部パネルを開くときの比率`のスライダー(上のガントチャートの割合 50〜90%・5% 刻み。数値も出す)だけ。動かすとすぐ画面に反映し、`適用`で保存、`キャンセル`・ESC・外側クリックで開く前に戻す(`今日の線の色…`のダイアログと同じ作り)。プロジェクトごとの設定(`プロジェクト`メニューの`設定`)とは別で、全プロジェクト共通の値だけを置く。既存の全体の設定(テーマ・今日の線の色・警告の色など)は、テーマのメニューのまま動かさない |
| `views.py` | 比率の保存・復元の受け渡し、終了時(`app.on_shutdown`)の保存 |

## 守るもの

- 画像の書き出しは、枠の中の`[data-chart-content]`を`scrollHeight`で撮るので、枠の高さに依存しない。変えない。
- スクロール位置の維持、名前欄の固定、`当日`の自動スクロール、矢印・今日の線の計算は変えない。
- 画面の拡大・縮小(`zoom`)で、分割の高さが崩れない。
- 保存形式(プロジェクトの JSON、`version`)は変えない。
- 集計は保存しない(表示のたびに計算する)。

## テスト

- 純粋関数: 詳細・集計・今日の予定・凡例の各条件(まとめ・チェックポイント・参照・工数なし・日程なし・終了・遅れ・警告・絞り込み・期間)
- 設定: `main_split`・`bottom_open_ratio`の読み書きと不正値(範囲外・型違い)
- 画面: 初回は 100%、選択で畳まれていれば 70% に開く(開いていれば動かさない)、スライダーの変更が反映される、終了時の保存と起動時の復元、分割の有無、選択で詳細に切り替わる、解除で集計に戻る、タブの切り替え、プレビューとダッシュボードで出ない、保存した比率の復元
- 既存の smoke と全テスト、`ruff`・`ty`

## 実装の段階

1. 分割と空のパネル、`main_split`の保存と復元、`開くときの比率`とそのスライダー(要望 111)
2. 集計の純粋関数と、パネルの集計・タブ(今日の予定・凡例)(要望 95)
3. 詳細(選択への連動)(要望 95)

段階ごとにテストを通し、全体は 1 つの PR にまとめる(段階ごとに分けるかは、計画で決める)。

## 範囲外

- パネルの中からのタスクの編集(編集は右クリックメニューの`編集`のまま)
- ホバーへの連動
- パネルの内容の設定(出す・出さないの切り替え)
- 既存の全体の設定(テーマ・今日の線の色・警告の色・倍率)の、`全体の設定`への移動(必要なら別の要望)
- ウィンドウの大きさ・位置の記憶(記憶するのは分割の位置だけ。名前欄の幅と画面の倍率は、すでに保存している)
- プレビュー・画像・PlantUML へのパネルの出力
