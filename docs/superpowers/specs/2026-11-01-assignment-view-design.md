# 下部パネルの割り当て表示の設計(要望 116)

> **状態**: 設計中(利用者のレビュー待ち)。architectural。

## 目的

ガントチャートを見ながら、担当者ごとの割り当て(負荷)を日ごとに確かめられるようにする。タスクの一覧とは別に、人ごとの偏りと割り当て超過を、画面を移らずに見られる。

## 利用者の要望(原文の要点)

- 下部パネルに、`Ctrl/Cmd + Alt/Option`で、タスクの割り当て状況を、日ごとのガントチャート風に表示する。上の`日次`/`週次`/`月次`の選択に合わせる。
- 切り替えは、押すたびに入れ替える(押している間だけではない)。
- 絞り込みに従う。週次・月次の数字は平均。

## 決めたこと

| 項目 | 決定 |
|---|---|
| 呼び名 | 下部パネルの`割り当て`ビュー |
| 切り替え | `Ctrl/Cmd`と`Alt/Option`の両方を押すたびに、`割り当て`ビューと元の内容(詳細または集計)を入れ替える。押しっぱなしの連続入力は無視。入力欄にフォーカスがあっても効く。畳んでいるときは、開くときの比率で開く。パネルの中に同じ切り替えのボタンも置く。ショートカットのヘルプにも載せる |
| 刻み | メインの`日次`/`週次`/`月次`の選択と同じ |
| 期間 | メインの表示期間。自動のときは、タスクの範囲 |
| 行 | 担当者(絞り込みに従う) |
| 数字 | 割り当て率(100% = 1.0)。日次はその日の合計。週次・月次はその期間の**平均** |
| 100% 超 | ガントチャートの縞(割り当て超過)と同じ見た目。週次・月次は、期間のどこかで 100% 超の日があれば縞にする |
| 稼働日でない日 | 休み・祝日・土日などは、ガントチャートと同じ背景色 |
| 絞り込み | 検索・担当者・チームで見えているタスクだけで計算し、その担当者の行だけを出す |
| 表示中の選択 | `割り当て`ビューを出している間にタスクを選んでも、下部パネルの内容は変えない(詳細に切り替えない。選択そのものは今までどおり行い、行の見た目も変わる)。選択の解除でも変えない。元の内容に戻るのは、もう一度切り替えたときだけ。戻ったときは、そのときの選択に合わせた内容(詳細または集計)を出す |
| 位置 | 第 1 段階は、独立してスクロールする表。ガントチャートの横スクロールとの連動は、別の要望(第 2 段階) |
| 保存 | ビューの状態は保存しない。ファイル形式(`version`)は変えない |

## 構成

| 部品 | 役割 |
|---|---|
| `bottom_info.py` | 割り当ての表を作る純粋関数(行=担当者、列=刻み、セル=割り当て率と超過の印)。負荷の計算は`dashboard`の`DayLoad`などの既存の関数を使い、新しい判定は作らない |
| `bottom_panel.py` | `割り当て`ビューの描画。切り替えのボタン |
| `gantt.py` | ビューの切り替えの状態、キーの受け取り(`Ctrl/Cmd`と`Alt/Option`の同時押し)、刻み・期間・絞り込みの受け渡し |
| `shortcuts.py` | ヘルプの一覧用の項目 |

## 守るもの

- 既存のキー(`Cmd+Option+I`など)に触れない。拾うのは修飾キーの同時押しだけ。
- ガントチャートの縞・休みの色と、同じ判定を使う。
- 絞り込みで隠れたタスクは数えない。
- プレビュー・ダッシュボードでは出さない(下部パネルと同じ)。

## テスト

- 純粋関数: 日・週・月の刻み、平均、100% 超の印、休み・祝日、絞り込み、担当者のいないタスク、期間の端
- 画面: `割り当て`ビュー中に選択・解除しても内容が変わらず、戻すとその時点の選択の詳細が出る、キーの同時押しで入れ替わる、連続入力は無視、畳んでいるときは開く、ボタンでも入れ替わる、刻みの変更に追従する、絞り込みに追従する、プレビューとダッシュボードでは出ない
- 既存の smoke と全テスト、`ruff`・`ty`

## 範囲外

- 表からの割り当ての編集、クリックでのタスク選択
- ガントチャートの横スクロールとの連動(第 2 段階。別の要望)
- 表示する指標の切り替え(平均以外)
