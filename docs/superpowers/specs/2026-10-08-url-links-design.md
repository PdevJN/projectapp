# タスクのリンクリスト 設計書

作成日: 2026-10-08
ブランチ: `feature/url-links`(`develop` から)
経路: architectural(設計書 → 実装計画 → 実行)
要望: 作業記録の要望 25「タスクのリンクリスト」

## 1. 目的と合意した範囲

タスクに、関連する URL(チケット・資料など)を複数登録して、一覧にし、開けるようにする。URL の型(テンプレート)をプロジェクト共通で登録しておき、リンクでは、テンプレートを選んで ID だけを入力できるようにする。

合意した決定(2026-10-08):

- 使う場面は、タスクの編集ダイアログの中だけ。ガントチャートには何も足さない(要素数を増やさない。要望 24)。
- リンク 1 件は、表示名(任意)・テンプレート・値を持つ。テンプレートは「テンプレートなし」が既定。
- テンプレートはプロジェクト共通で、設定ダイアログで登録する(名前と URL の型)。型の中の `{ID}` を、リンクの値で置き換える。
- 変数は `{ID}` だけ。ただし保存は名前付きの辞書にして、複数の変数への拡張で形式が壊れないようにする。
- テンプレートを削除するときは、確認ダイアログを出し、そのテンプレートを使うリンクは、置き換え済みの URL に展開して残す(「テンプレートなし」になる)。リンクは消さない。
- チェックポイントにも付けられる。

やらないこと: ガントチャートへのリンクの表示(件数のチップなど)、複数の変数、ドラッグでのリンクの並べ替え、担当者向けの書き出し(`todos.json`)への出力、添付ファイル(別の機能)、リンク先の到達確認。

## 2. データ(`models.py`・`storage.py`)

名前の衝突を避ける。タスク同士の連結は `predecessors`(`links.py`・`linkgraph.py`)で、すでにある。今回の機能は `urls` と呼ぶ。

- `UrlTemplate`: `name: str`(表示名。前後の空白を除く。必須・プロジェクト内で重複不可)、`pattern: str`(URL の型。`http://` か `https://` で始まる)。
- `TaskUrl`: `title: str = ""`(表示名。任意)、`template: str | None = None`(テンプレート名。`None` は「テンプレートなし」)、`values: dict[str, str]`(テンプレートありのときは `{"ID": "231"}`。なしのときは `{"URL": "https://…"}`)。
- `Project.url_templates: list[UrlTemplate]`、`Task.urls: list[TaskUrl]`。
- 保存:
  - プロジェクト: `"url_templates": [{"name": …, "pattern": …}]`。
  - タスク: `"urls": [{"title": …, "template": …または null, "values": {…}}]`。
  - キーがない・`null` は空リスト(古いファイルを移行なしで読む)。
- 読込で拒否する(「開けませんでした」):
  - 名前が空、または重複するテンプレート。
  - `pattern` が `http://`・`https://` で始まらない。
  - 存在しないテンプレート名を指すリンク。
  - 値が空(テンプレートありは `ID`、なしは `URL`)、またはキーが期待と違う。
  - 型が違う(文字列でない、辞書でない、など)。
- 開く URL の決め方(`urls.resolve`): テンプレートありなら、`pattern` の `{ID}` を、URL エンコードした ID で置き換える(`{ID}` がなければ `pattern` のまま)。なしなら `URL` の値そのまま。結果は `http://`・`https://` で始まるものだけを許可する(`file:`・`javascript:` などは拒否)。
- 置き換えは `str.replace` だけで行う(`str.format` は、`{` を含む型で例外になるので使わない)。
- チェックポイントにも付けられる。チェックポイントの不変条件(`kind` の節)に `urls` は含めない。

## 3. 規則を持つ純粋関数(`urls.py`)

NiceGUI から切り離す。

- `resolve(link, templates) -> str`: 上記の規則で開く URL を返す。許可しないスキームや空の値は `ValueError`。
- `validate_templates(templates) -> None`: 名前の空・重複、`pattern` のスキームを検証し、違反は `ValueError`(メッセージは画面にそのまま出せる日本語)。
- `validate_urls(urls, templates) -> None`: テンプレートの存在、値の空、解決後の URL のスキームを検証する。
- `expand_template(project, name) -> int`: そのテンプレートを使うリンクを、全タスクで、置き換え済みの URL に展開して「テンプレートなし」にする。展開した件数を返す。表示名は残す。
- `count_usage(project, name) -> int`: そのテンプレートを使うリンクの件数(確認ダイアログ用)。
- `rename_templates(project, renames) -> None`: テンプレート名の変更(元の名前 → 新しい名前)を、リンクの参照へ一度に反映する。入れ替え(A↔B)でも混ざらない。
- `TemplateEdit(templates, renames, removed)` と `apply_template_edit(project, edit) -> None`: 設定ダイアログの編集結果。削除分を古い型で展開 → 名前の変更 → 一覧の置き換えの順で反映する(削除して同名で作り直しても、古いリンクは古い型で展開される)。

## 4. 画面

### 設定ダイアログ(テンプレートの編集)

- 「URL テンプレート」の節を足す。1 行が、名前・URL の型の 2 欄で、行の追加と削除ができる。
- 保存時の検証は `validate_templates`。違反は保存せずメッセージを出す。
- 削除した行に使用中のリンクがあれば(`count_usage` の合計)、確認ダイアログを出す:「このテンプレートを使っているリンクが N 件あります。URL としてそのまま残ります」。選択肢は `削除する`・`キャンセル`。件数が 0 なら確認なしで保存する。確認で `削除する` を選んだときだけ、`expand_template` で展開して保存する。
- 名前を変えた行は `rename_templates` でリンクの参照を追従させる。名前の変更と削除は、行の識別(行ごとの内部 ID)で見分ける。
- 設定は「保存」を押すまで確定しないので、削除の確認も保存時に出す。
- `on_apply` の署名は変えず、テンプレートの編集結果は別の引数 `on_templates(TemplateEdit)` で渡す(変更があるときだけ呼ぶ)。名前も型も空の追加行は無視する。

### タスクの編集ダイアログ(リンクの編集)

- 「リンク」の節を足す。1 行が `表示名(任意)`・`テンプレート`(選択。先頭が「テンプレートなし」で既定)・`値` の 3 欄で、行の追加と削除ができる。
- 「値」欄のラベルは、テンプレートなしなら「URL」、ありなら「ID」に切り替える。
- 各行に「開く」ボタンを置き、OS の既定のブラウザで開く。開けなければ通知する。
- 保存時の検証は `validate_urls`。違反は保存せずメッセージを出す。
- 開く処理は `filemanager.py` と同じ形の薄い関数(標準の `webbrowser`)にし、テストでは偽物に差し替える。

### ガントチャート・書き出し

変更しない。`todos.json`(担当者向け)にも出さない。

## 6. テスト

- `urls.py` の単体: ID のエンコード、`{ID}` のない型、`{` を含む型、許可しないスキームの拒否、展開(件数・表示名の保持)、名前の変更、使用件数、検証メッセージ。
- 保存と読込: 往復、古いファイル(キーなし)が空で読める、不正な値の拒否(上の「読込で拒否する」の各項目)。
- 設定ダイアログ: 行の追加・削除、検証エラーで保存されない、使用中のテンプレートを削除すると確認が出て件数が出る、`削除する` で展開される、`キャンセル` で何も変わらない、件数 0 は確認なしで削除、名前の変更が参照に反映される。
- タスクの編集ダイアログ: 行の追加・削除、テンプレートの切り替えで「値」のラベルが変わる、検証エラーで保存されない、「開く」で偽物が解決後の URL で呼ばれる、開けないときに通知する、チェックポイントでも保存できる。
