# メンバーのアイコンの設計(要望 41)

> **状態**: 完了(PR #51。実機確認済み。2026-10-18)— 要望 41。現在の仕様は [`CLAUDE.md`](../../../CLAUDE.md) に反映済み。要望 41〜46(チームのダッシュボードとメンバーの拡張)の最初の項目。

## 目的

メンバーに、画像のアイコンを設定できるようにする。設定されていれば表示し、なければ今の頭文字のチップのままにする。Slack のアイコンを想定する。
成功の目安は次のとおり。

- メンバーのダイアログで、保存してある画像ファイル(Slack のアイコンなど)を選んで設定でき、外せる。
- 設定したアイコンが、ガントチャートの担当者チップ・ダッシュボードの人ごとの負荷・プレビュー・PNG に出る。
- アイコンは、プロジェクトのファイル 1 枚に入る(別ファイルを作らない)。

## 決めたこと

| 項目 | 決定 |
| --- | --- |
| 入手方法 | 画像ファイルを選ぶ(ネイティブのファイル選択)。URL の入力・Slack API からの取得はしない |
| 保存場所 | `Member.icon` に data URI で埋め込む(プロジェクトのファイル 1 枚の原則、git・同期・マージにそのまま乗る) |
| 取り込む形式 | PNG・JPEG・GIF・WebP。SVG は取り込まない(スクリプトを含められるため。`data:` で出す表示を避ける) |
| 縮小 | 中央を正方形に切り抜き、128×128 の PNG にする(透過は保つ) |
| 縮小の実装 | Pillow を依存に足し、`icons.py`(純粋関数)に切り出す |
| 出さない場所 | タスクの編集ダイアログの担当者の選択、担当者のフィルタ、担当者向けファイル(`todos.json`)、PlantUML |
| `version` | 7 にする。休暇・不在(要望 44)は 8 になる |

## モデル

- `Member.icon: str = ""`。空はアイコンなし。値は `data:image/png;base64,<base64>` の形に限る。
- 読込の検証(不正な値は読込を拒否する):
  - `data:image/png;base64,` で始まる。
  - base64 として正しい。
  - デコードしたあとの大きさが 64KB 以下。
  - Pillow で PNG として開ける。
- キーのない古いファイル(`version` 6 以前)は、アイコンなしとして読む。このアプリより新しい `version` は、今までどおり拒否する。
- アイコンは `Member` が持つ。改名では保持され、メンバーを消すと一緒に消える。同名で作り直しても引き継がない。

## 取り込み(`icons.py`)

- `make_icon(data: bytes) -> str`: 画像のバイト列から、data URI を返す。取り込めないときは `IconError`(理由の文面つき)を投げる。
  - 元ファイルは 10MB まで。超えるときは拒否する。
  - 形式は Pillow が判別した PNG・JPEG・GIF・WebP だけ。それ以外(SVG・画像でないファイル・壊れた画像・空)は拒否する。
  - GIF・WebP のアニメーションは、最初のフレームを使う。
  - 中央を正方形に切り抜き、128×128 に縮小して PNG で保存する。出力が 64KB を超えるときは拒否する(通常は数 KB〜数十 KB)。
- `is_valid_icon(value: str) -> bool`: 保存・読込の検証が使う。

## 表示

表示の入口は 1 つの部品 `avatar(member, size)` に集める。アイコンがあれば丸い画像を、なければ今と同じ頭文字のチップを出す。画像が壊れていて表示できないときは、頭文字に戻す。

| 場所 | 内容 |
| --- | --- |
| ガントチャートの名前の欄の担当者チップ | 頭文字の代わりにアイコン。マウスオーバー(名前と割り当て率)と、4 人目以降の`+n`のまとめは今のまま |
| メンバーのダイアログ | 表に「アイコン」の列を足す(プレビュー・`選ぶ`・`外す`)。適用までは確定しない(未適用の編集と同じ扱いで、タブの見出しに`●`が出る) |
| ダッシュボードの人ごとの負荷 | メンバー名の左に出す |
| プレビュー・PNG 保存 | チップと同じ表示(data URI なので、そのまま書き出せる) |

- 形は円で、チップと同じ大きさ。細い枠を付け、ダークテーマでも埋もれないようにする。
- `選ぶ`は、ネイティブウィンドウのときだけ出す(`ask_open_path`を使い回す)。ブラウザでは出さない(`外す`と表示は動く)。

## 元に戻す・マージ

- アイコンの設定・削除は、他のメンバーの編集と同じく、元に戻す・やり直しの対象にする(適用 = 1 ステップ)。
- `merge.py`では、メンバーの項目の 1 つとして比べる。片側だけが変えた値を採り、両側が違う値に変えたときは、`自分`か`相手`から選ぶ。

## エラー処理

- ファイル選択のキャンセルでは、何も起きない。
- 取り込めない画像は、理由を通知して、今の状態を変えない。
- 読込でアイコンが不正なファイルは、読込を拒否する(他の項目と同じ)。

## テスト

| 対象 | 内容 |
| --- | --- |
| `icons.py` | 正方形への切り抜きと縮小、PNG・JPEG・GIF・WebP、アルファ付き PNG、1×1 や極端な縦長、アニメーション、壊れた画像・空・SVG・画像でないファイル・10MB 超の拒否、出力が 64KB 以下 |
| `storage.py` | 保存と読込の往復。`version` 6 のファイルはアイコンなしで読める。`data:` の形・base64・大きさ・中身が不正なら拒否。新しい`version`は拒否のまま |
| `merge.py` | 片側だけの変更、両側が違う変更 |
| `avatar` | アイコンありで画像、なしで頭文字、壊れた値で頭文字に戻る。チップの`+n`・マウスオーバーが変わらない |
| メンバーのダイアログ | 選ぶ・外す・キャンセルで破棄・適用で確定、`●`の表示、改名で残る |
| 元に戻す | 設定・削除が 1 ステップで戻る |
| ダッシュボード・プレビュー | 人ごとの負荷の行・プレビュー・PNG にアイコンが出る |
