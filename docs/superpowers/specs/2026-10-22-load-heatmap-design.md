# 負荷の日ごとのヒートマップの設計(要望 47)

> **状態**: 実装済み(2026-10-22)— 要望 47 — `feature/load-heatmap`。現在の仕様は実装後に [`CLAUDE.md`](../../../CLAUDE.md) へ反映する。

## 目的

要望 31 の「人ごとの負荷」は、平均・最大・100% 超の日数までで、どの日が超過しているかは分からない。
人を行、稼働日を列にした表で、日ごとの割り当て率の合計を色で示し、100% を超える日を一目で見つけられるようにする。
成功の目安は次のとおり。

- `全プロジェクト` がオンのとき、「人ごとの負荷」の下に、人×稼働日の表が出る。
- 100% を超える日は、赤と太い枠線で目立つ。
- セルのマウスオーバーで、その日の合計とプロジェクト別の内訳が分かる。
- ファイル形式(`version`)は変えない。

## 決めたこと(2026-10-22 に確認済み)

| 項目 | 決定 |
| --- | --- |
| 置き場所 | 独立した全幅のカード。`全プロジェクト` がオンのときだけ出す |
| 長い期間 | 稼働日を 1 列ずつ並べ、横スクロール。名前の列は固定。週・月への集約はしない |
| セルの値 | 要望 31 と同じ「その日の同時刻の割り当て率の合計の最大」 |
| 色 | 0% は塗りなし。1〜100% は青、100% 超は赤(濃さは値に比例)と太い枠線。文字は入れない |
| マウスオーバー | `title` 属性。合計とプロジェクト別の内訳 |

## 集計(`dashboard.py`)

- 型を足す。
  - `ProjectPeak(project: str, peak: float)`: その日、そのプロジェクトだけで見た割り当て率の合計の最大
  - `DayLoad(day: date, total: float, by_project: list[ProjectPeak])`: `total` は全プロジェクトを重ねた値。`by_project` には `peak` が 0 より大きいプロジェクトだけを入れる
- `CrossLoad` に `days: list[DayLoad]` を足す(既定は空のリスト)。`summarize_cross_loads` が稼働日ごとに埋める。
- 内部の `_load_stats(items, days)` を、日ごとの合計を返す `_day_totals(items, days)` と、それを受け取る `_stats_of(totals)` に分ける。`summarize_loads` の結果は変えない。
- `days` の `total` から求めた平均・最大・超過日数は、`CrossLoad.total`(`LoadStats`)と一致する。
- 稼働日だけが対象(土日・祝日は列に出さない)。期間は要望 31 と同じ。

## 表の描画(`dashboard_view.py`)

- `全プロジェクト` がオンで、人が 1 人以上いるときだけ、「人ごとの負荷」の下に全幅のカード `負荷の日ごとの推移`(マーカー `dashboard-heatmap`)を出す。オフのとき・人が 0 人のときは出さない。
- 行は人(「人ごとの負荷」と同じ順)、列は稼働日。見出しは `10/22` の下に曜日を 1 文字。
- 表は 1 つの HTML の塊として描く(`ui.html`、ガントチャートの見出しと同じ作法)。名前・プロジェクト名・日付は `html.escape` する。
- カードの中を横スクロールにし、名前の列は `position: sticky; left: 0` で固定する。見出しの行は固定しない。セルは幅 26px(見出しの `10/22` が収まる幅)の小さな四角で、文字は入れない。
- 色:
  - 0%: 塗りなし(薄い枠だけ)
  - 1〜100%: 既存の `LOAD_COLOR` で、濃さを値に比例させる
  - 100% 超: 既存の `OVER_COLOR` で、濃さを超過の度合い(〜200%)に比例させ、太い枠線を付ける(色だけに頼らない)
  - 濃さは透明度で表し、ライト・ダークの両方で背景に合わせる
- 凡例を一行で、カードの上に出す(0%・50%・100%・超過)。
- マウスオーバー(各セルの `title`): `田中 10/22(木) 180%` の次の行に `A 60% / B 60% / C 60%`。0% のセルは合計だけ。
- 稼働日が 0 日の期間は、見出しも行も出さず `稼働日がありません` を出す。

## 含まないもの

セルのクリックでの操作、週・月への集約、1 プロジェクトだけの表(横断オフ時)、横断の進捗・工数の表、見出しの行の固定、書き出し。`views.py`・`portfolio.py` は変えない。

## テスト

- 集計(`test_dashboard.py`):
  - `days` の `total` から求めた平均・最大・超過日数が `LoadStats` と一致する。
  - A+B が重なる日は `total` が足され、`by_project` に両方が入る。片方だけの日は 1 件。0% の日は空。
  - 土日・祝日は `days` に入らない。
  - 1 プロジェクトのときも `days` が埋まる。
- ビュー(`test_dashboard_view.py`):
  - 横断オフでは、カードが出ない。
  - 横断オンで、人×日付のセルが出る(`data-cell`)。
  - 超過のセルに、赤の色と太い枠線が付く。
  - マウスオーバーに内訳が出る。
  - 名前に `<` などが入っていても、エスケープされる。
  - 稼働日が 0 日のとき、`稼働日がありません` が出る。
- 配線(`test_views.py`): 横断オンで、除外したプロジェクトが表に入らない。
- 実行: `uv run pytest -n auto -q`、型チェックは `uv run ty check src`。実機では、数百列(`全期間`)でも重くないかを確認する。
