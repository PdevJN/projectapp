# 俯瞰図(系統図)の設計(要望 147)

2026-11-15 作成。対象は`docs/requests.md`の要望 147。

## 目的

セクションやまとめの配下の構成を、ツリー状の図で一目で見られるようにする。先行・後続の矢印は出さず、階層(セクション → サブセクション → まとめ → 子タスク)だけを示す。

## 決定事項(2026-11-15 に確認済み)

| 項目 | 決定 |
|---|---|
| 図の中身 | 階層のツリーだけ。先行・後続の矢印は出さない |
| ノードの情報 | 名前と状態の色は必ず出す。`進捗`と`工数・完了予定`は、チェックボックスで隠せる(既定はどちらも表示) |
| 担当者 | 出さない |
| 表示する範囲(2026-11-16 に追加) | 既定は、セクションとまとめだけ。上部のチェックボックス`タスクの詳細`(既定はオフ。保存しない)をオンにすると、通常タスク・チェックポイント・プロジェクト参照も出す。隠していても、セクションとまとめの進捗・工数・状態は、配下のタスクから集計した値を出す。まとめを根にして開くと、既定では、まとめのノードだけになるので、図の中に`タスクの詳細`の案内を出す |
| 長い名前(2026-11-16 に追加) | 名前は折り返す。全角を幅 1、半角を幅 0.5 として、1 行 15 文字分で折り、3 行まで。超える分は、3 行目の末尾を`…`で切る。画面と PDF は同じ行を使う |
| 入口 | セクション見出しとまとめ行の右クリックメニューの`俯瞰図…`。その配下を根にする |
| ノードのクリック | ダイアログを閉じ、ガントチャートのその行へスクロールする(折りたたまれていれば展開する)。セクションのノードは、中の最初のタスクの行へ(中にタスクがなければ閉じるだけ) |
| PDF | ダイアログの`PDF に出力`。Pillow で画像に描いて PDF 化する。保存先はネイティブのファイル保存ダイアログで選ぶ。Web モードでは通知で断る |
| 描画 | NiceGUI の要素と CSS による自前描画(外部ライブラリは使わない) |
| 保存 | チェックボックスの状態は保存しない。ファイル形式は変えないので`version`は上げない |

## 構成

### `overview.py`(純粋関数。NiceGUI に依存しない)

- `OverviewNode`: `id`・`name`・`kind`(セクション・まとめ・通常・チェックポイント・プロジェクト参照)・`status`・`progress`(0〜100 か`None`)・`effort_hours`・`due`(完了予定か`None`)・`depth`・`children`。
- `build_overview(project, root)`: 根(セクションの位置か、まとめのタスク id)の配下をツリーにする。
  - まとめの子は`task.children`の順。セクションの中は、画面と同じ並び順。
  - プロジェクト参照の行は、子を持たない 1 ノード。
  - 配下が空のセクションは、根のノードだけの図にする。
- 進捗の集計: タスクは自分の進捗(`終了`は 100)。セクション・まとめは、配下の通常タスクの、工数で重みづけした進捗率。重みと進み具合は`dashboard._progress_weight`をそのまま使う(`bottom_info.py`・`reference.py`と同じ import)。プロジェクト参照のノードは進捗を出さない。チェックポイントは除く。集計の対象がなければ`None`(表示しない)。
- `wrap_name(name)`: 名前の折り返し(上記)。`node_lines`の先頭の`Placed.name_lines`行が名前になる。
- `layout_overview(root, show_progress, show_effort, show_tasks=True)`(`show_tasks`が偽なら、セクションとまとめだけを残してから座標を計算する): 各ノードの座標とサイズ、枝の線(親の右端 → 子の左端)を返す。左から右へ、深さが列、兄弟が縦に並ぶ。ノードの高さは、隠した項目の行を除いて詰める。画面と PDF は同じ結果を使う。
- 遅れ(赤)・警告(黄)は、既存の状態の色の関数をそのまま使い、新しい判定は作らない。

### `overview_dialog.py`(NiceGUI)

- 上部: `タスクの詳細`(既定はオフ)・`進捗`・`工数・完了予定`のチェックボックス(オン/オフで図を作り直す)と`PDF に出力`ボタン。
- 本体: `layout_overview`の座標で、ノードを絶対配置の要素で描き、枝は CSS の線で結ぶ。大きい図は、`overflow: auto`の領域でスクロールする。
- ノードをクリックすると、ダイアログを閉じ、ガントチャートのその行へスクロールする(折りたたまれていれば展開する)。
- 開くたびに、その時点のプロジェクトから作る(図は保存しない)。
- `refreshable`の中でダイアログを作らない(既存の学びに従う)。

### `overview_pdf.py`(Pillow)

- 同じ座標を、2 倍の解像度で描き、`Image.save(path, "PDF")`で書き出す。用紙は、図の大きさに合わせた 1 ページ(横長)。
- 日本語フォントは OS のものを探す(macOS はヒラギノ、Windows はメイリオ、Linux は Noto CJK)。見つからなければ通知で断り、ファイルは作らない。
- 隠した項目は、PDF にも出さない。
- 保存先はネイティブの保存ダイアログ(`export.py`の既存の方式)で選ぶ。Web モードでは通知で断る。
- 一時ファイルに書いてから置き換え、失敗したときは通知を出して、既存のファイルは壊さない。

### 右クリックメニュー

- ガントチャートのセクション見出し(1〜3 階層)と、まとめ行の右クリックのメニューに`俯瞰図…`を足す。通常タスクの行には出さない。
- プレビュー(読み取り専用)では、既存のセクション・タスクのメニューと同じく、メニュー自体を出さない(俯瞰図は開けない)。

## テスト

- `overview.py`: 階層の変換(セクション・サブセクション・まとめ)、進捗の集計(重み・終了・チェックポイントを除く・対象なしは`None`)、空のセクション、プロジェクト参照、座標の重なりがないこと、項目を隠したときの高さ。
- `overview_pdf.py`: 出力の先頭が`%PDF`であること、フォントが見つからないときに断ること(フォント探しを差し替えて確認)。
- ダイアログ: チェックボックスで図が変わること、ノードのクリックでガントチャートへ移ること(smoke)。
- 右クリックのメニュー: セクション見出しと、まとめの行でだけ`俯瞰図…`が出ること(通常タスクでは押せない・出ない)。

## 範囲外
