# タスクのメモ(要望 150)設計書

2026-11-18。経路: architectural。決めた方針は、利用者との対話で承認済み(保存先・形式・削除と複製・画面・同期の考え方)。

## 背景と目的

タスクごとに、補足(経緯・手順・リンクなど)を書き留めたい。ただし、プロジェクトのファイルは git 管理の対象で、メモを入れると、チームで共有する内容になってしまう。そこで、git 管理の外に置くリッチテキストのメモを、タスクに紐づけて持てるようにする。利用者には、仕組みの違い(git に載らないこと)を意識させない。

## 決めたこと(承認済み)

| 点 | 決定 |
|---|---|
| 保存先 | `~/.projectapp/notes/<プロジェクト名>/<タスクid>.html`(設定フォルダの下。格納先を git 管理していても影響しない) |
| 形式 | HTML(NiceGUI の`ui.editor`が出す HTML をそのまま保存) |
| 有無の判定 | ファイルがあるか。プロジェクトのファイルは変えない(`version`は 23 のまま) |
| 入口 | タスクの右クリック`メモ…`、タスク名の後ろの`🗒️`のクリック |
| 画面 | ガントチャートの右に開く右ペイン(上にタスク名、下にエディタ) |
| 削除 | タスクを削除したらメモも消す。`元に戻す`で戻せる |
| 複製 | メモもコピーする |
| 別の端末 | メモはその端末のローカル。別の端末・別のクローンには`🗒️`が出ない(仕様) |

## 保存(`notes.py`。NiceGUI から切り離す)

```python
def notes_dir(project_name: str) -> Path: ...                  # ~/.projectapp/notes/<名前>
def load(project_name: str, task_id: str) -> str | None: ...   # なければ None
def save(project_name: str, task_id: str, html: str) -> None: ... # 空(タグを除いて空白だけ)なら削除
def exists(project_name: str, task_id: str) -> bool: ...
def delete(project_name: str, task_id: str) -> str | None: ... # 消して、消した中身を返す
def copy(project_name: str, src_id: str, dst_id: str) -> None: ...
def copy_project(src_name: str, dst_name: str) -> None: ...    # 名前をつけて保存で、メモごと新しい名前へ
def move_project(old_name: str, new_name: str) -> None: ...    # 名前が変わるとき(将来の要望 142 が使う)
```

- 保存は一時ファイル経由(`storage.py`と同じ)。ファイル名は`<タスクid>.html`で、id は英数字とハイフンだけ(それ以外の文字を含む id は拒否する。パスの混入を防ぐ)。
- プロジェクト名がフォルダ名として使えない文字を含むときは、`storage.py`のファイル名の規則に合わせる。
- 空かどうかは、タグを除いた文字列を`strip`して判定する(`<p><br></p>`だけのメモを残さない)。
- 読めない・壊れたファイルは、メモなしとして扱う(例外を画面に出さない)。

## 画面

### 右ペイン
- ガントチャートの右に、幅を変えられるペインを開く(既定 360px。左端をドラッグして変える。画面の倍率に追従)。閉じるボタンと`Esc`で閉じる。
- 上にタスク名(1 行、長いときは省略)、下に`ui.editor`(太字・斜体・下線・箇条書き・番号・リンク・見出しなど。`ui.editor`の標準のツールバー)。
- 保存は、入力が約 1 秒止まったとき・ほかのタスクの`🗒️`を押したとき・閉じたときに自動で行う(ボタンはない)。空にして保存すると、メモのファイルを消し、`🗒️`も外れる。
- ペインを開いている間、ガントチャートの横幅はペインの分だけ狭くなる。倍率が高いときに、ガントが見えなくなるほど広がらない(ペインの最大幅は画面の 60%)。

### 入口
- 右クリックの`メモ…`: 開く(なければ空のメモを開く。入力するまでファイルは作らない)。
- タスク名の後ろの`🗒️`: メモがあるタスクにだけ付く。クリックで開く。マーカーは`task-note-<id>`。
- まとめ・節目・プロジェクト参照のタスクにも付けられる(id を持つ行すべて)。セクションの行には付けない。
- 開いている最中にそのタスクが削除されたら、ペインを閉じる。

## 削除・複製・元に戻す

`history`はプロジェクトのスナップショットだけを持ち、メモのファイルは持たない。そこで、ビューが「タスク id の増減」を見て、メモを同期する。

- ビューは、編集・元に戻す・やり直しのたびに、変更前後のタスク id の集合を比べる(`notes.sync`。純粋関数に近い形で、`(前の id, 後の id, ごみ箱) → 操作の一覧`を返す)。
- 増えずに**消えた id**にメモのファイルがあれば、中身をビューの**ごみ箱**(メモリ上の`dict[id, html]`)に移してから、ファイルを消す。
- **戻った id**(ごみ箱にある id が、後の集合に現れた)は、ごみ箱の中身をファイルへ書き戻す。
- 変更前後の差だけを見るので、`git pull`の取り込みや外部の変更で消えた id のメモは、触らない(ごみ箱に入れない)。ごみ箱に入れるのは、アプリの操作(削除・まとめて削除・分解など)で消えたタスクだけ。
- ごみ箱は、プロジェクトを閉じる・切り替えるときに捨てる(そのあとは戻せない)。
- 複製(`copy_task`・`copy_task_below`・セクションのコピー)は、新しい id へメモをコピーする。コピーしたタスクの`🗒️`が付く。
- `名前をつけて保存`は、メモのフォルダも新しい名前へコピーする(元のメモは残す)。

## 計算・データ形式への影響

- なし。完了予定・工数・進捗・マージ・書き出し(PlantUML・CSV・担当者向け)は、メモを読まない。プロジェクトのファイルの形(`version`)は変えない。
- 担当者向けファイル・PlantUML・CSV には、メモを出さない(git 管理外の内容を、書き出しで漏らさない)。

## 触る場所

- 新規: `notes.py`(保存・同期)、`note_pane.py`(右ペイン)。
- 変更: `views.py`(右クリックのメニュー・同期の呼び出し・`名前をつけて保存`)、`gantt.py`(タスク名の後ろの`🗒️`。メモのあるタスクの id の集合をビューが渡す)、`.claude/spec/gantt.md`(右クリックと`🗒️`)・`project-files.md`(メモの保存先)、`docs/development.md`(モジュール構成)、`docs/requests.md`(状態)。

## テスト

- `notes.py`: 保存・読み込み・空で削除・壊れたファイル・不正な id の拒否・コピー・移動・同期(消えた id・戻った id・外部で消えた id は触らない)。
- ビュー: 右クリックの`メモ…`でペインが開く・入力して保存・`🗒️`が付く・削除してから元に戻すとメモが戻る・複製でコピーされる・`名前をつけて保存`でコピーされる。
- ガント: メモのあるタスクにだけ`🗒️`が付く。メモのないタスクの描画は変わらない(要素数を増やさない制約を守る)。

## 実機で確認すること

- ペインを開いたときの、ガントの横スクロールと、倍率(70%・100% 超)の見え方。
- 日本語入力の変換中に、自動保存がエディタの入力を壊さないこと。

## 見送り

- メモの検索・書き出し・別の端末への同期。
- 使われなくなったメモ(タスクが消えたあとに残ったもの)の整理。
- 画像の貼り付け。
